web

A web framework over the runtime's http.Server: a router with path parameters, middleware, cookies, form and query parsing, and static files.

Bring it in with import web. Build a Router of routes and middleware; web.serve(server, app) runs routers on an http.Server, calling app to set up a router for each request. A handler gets a Context (the request, its path parameters, and helpers for the query, cookies and body) and returns an http.Response.

  • Router, Context, Handler, Middleware, serve: routing
  • text, html, json_response, redirect, log_requests: responses and a logging middleware
  • Cookie, SameSite, set_cookie, parse_cookies: cookies
  • Form, FormFile, parse_form: form bodies, multipart included
  • static_files, content_type, MAX_GZIP_SIZE, MAX_GZIP_CACHE_SIZE: static files

Example

import async;
import http;
import io;
import web;

app(router: web.Router) {
    router.use(web.log_requests);
    router.get("/hello/{name}", (c) => web.text("hello, " + c.param("name")));
    router.get("/static/{*path}", web.static_files(io.Path("public")));
}

main(): int {
    async.run(() => {
        var server = http.Server.bind(io.SocketAddress.parse("127.0.0.1:8080").value()).value();
        web.serve(server, app);
    });
    return 0;
}

Router

struct Router

Sends each request to the handler of the first route whose method and path pattern match it, through the router's middleware.

A pattern is a path whose segments are literal text, {name} (any one segment, as the parameter name) or, as the last segment, {*name} (the rest of the path, slashes included, possibly empty). Literal segments and parameters are compared after percent-decoding, segment by segment. A HEAD request also matches GET routes (the server sends no body).

A path no route matches gets 404 Not Found; a path that matches only routes of other methods gets 405 Method Not Allowed with an Allow field; a path with an invalid percent-escape gets 400 Bad Request. These pass through the middleware too.

A router is used on one thread; serve builds one for each request.

Example

var router = web.Router();
router.get("/users/{id}", (c) => web.text("user " + c.param("id")));
router.get("/files/{*path}", (c) => web.text("file " + c.param("path")));
var response = router.handle(http.Request("GET", "/users/42"));   # 200, "user 42"

serve

serve(server: http.Server, app: shared (Router) => void)

Serves requests from server with a router that app sets up, until the task is cancelled (when async.run ends). For each request it makes a Router, calls app to add the routes and middleware, and lets the router answer. A router and its handlers are not thread-safe, so they are not shared between the worker threads of async.run: keep app to adding routes, and put state the handlers share, such as a connection pool or a counter, in a [Shared] struct (or an async.Atomic<T>) at module scope.

Parameters

  • server — the server, from http.Server.bind or bind_tls
  • app — adds the routes and middleware to a new router

Panics

  • outside async.run

Example

routes(router: web.Router) {
    router.get("/", (c) => web.text("hello"));
}

main(): int {
    async.run(() => {
        var server = http.Server.bind(io.SocketAddress.parse("127.0.0.1:8080").value()).value();
        web.serve(server, routes);
    });
    return 0;
}

static.pep

Static files: static_files serves a folder with content types, ETag and If-None-Match, single Range requests, and gzip for text; content_type maps a file name to its media type.

Source: static.pep

MAX_GZIP_SIZE

const MAX_GZIP_SIZE: ulong = 4194304

The largest file static_files compresses with gzip: 4 MiB. Larger files are sent as they are, streamed from disk.

static_files

static_files(root: io.Path): Handler

Returns a handler that serves the files under root for GET and HEAD routes whose pattern ends in {*path}: the file at root joined with the request's path parameter (index.html for a folder).

It refuses a path that could leave root with 404 Not Found: one with a .. segment, an absolute path, a backslash, a drive or stream name (:), or a NUL, in plain or percent-encoded form (the router decodes the path before the handler checks it). It does not follow the path's symbolic links any differently from the system, so a link inside root that points outside it is served.

A file is sent with the Content-Type that content_type gives, an ETag made from its size and modification time, and Accept-Ranges: bytes. A request whose If-None-Match lists the ETag gets 304 Not Modified. A single Range: bytes=... gets 206 Partial Content (or 416 Range Not Satisfiable), unless an If-Range names another ETag; several ranges get the whole file. A text file (text/*, JSON, JavaScript, SVG, XML) of at most MAX_GZIP_SIZE bytes is gzipped for a client that accepts it, with Vary: Accept-Encoding. The gzipped body is kept in memory (up to MAX_GZIP_CACHE_SIZE bytes over all files) and made again only when the file's size or modification time changes, or after it was dropped to make room.

Parameters

  • root — the folder to serve

Returns

  • the handler

Example

var router = web.Router();
router.get("/assets/{*path}", web.static_files(io.Path("public")));
