parse_form

parse_form(request: http.Request): Result<Form>

Parses the body of request as a form, by its Content-Type: application/x-www-form-urlencoded (+ is a space, percent-escapes are decoded) or multipart/form-data (RFC 7578), whose parts with a filename become files and the rest fields, decoded as UTF-8.

Parameters

  • request — the request

Returns

  • the form; an error for another content type, a missing or invalid boundary (RFC 2046: 1 to 70 characters), an invalid percent-escape, or a multipart body that is not well formed
