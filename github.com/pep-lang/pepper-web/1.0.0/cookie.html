cookie.pep

Cookies (RFC 6265): Cookie and set_cookie write Set-Cookie; parse_cookies reads a Cookie field. Context.cookie reads one cookie of a request.

Source: cookie.pep

SameSite

enum SameSite

The SameSite attribute of a cookie: whether the browser sends it with requests that other sites start.

Cases

Default

Default

No attribute; the browser's default applies (Lax in current ones).

Lax

Lax

Sent with top-level navigations from other sites, not with their subrequests.

Strict

Strict

Sent only with requests this site starts.

None

None

Sent with every request; browsers require secure with it.

Cookie

struct Cookie

A cookie to set on the client, with its attributes. Write it into a response with set_cookie.

Example

var session = web.Cookie("session", "abc123");
session.http_only = true;
session.secure = true;
session.same_site = web.SameSite.Lax;
session.max_age = Optional<long>.Value(3600);
web.set_cookie(response, session);

Fields

name

var name: String

The name: an HTTP token (letters, digits and !#$%&'*+-.^_`|~).

value

var value: String

The value: printable ASCII except space, ", ,, ; and \. Encode other text first, such as with Uri.encode.

path

var path: String

The Path attribute; empty for none (the browser uses the request's directory).

domain

var domain: String

The Domain attribute; empty for none (only the host that set it).

max_age

var max_age: long?

The Max-Age attribute in seconds; 0 or less deletes the cookie. None for a session cookie, unless expires is set.

expires

var expires: time.OffsetDateTime?

The Expires attribute; none for none.

secure

var secure: bool

The Secure attribute: sent only over HTTPS.

http_only

var http_only: bool

The HttpOnly attribute: hidden from scripts in the page.

same_site

var same_site: SameSite

The SameSite attribute.

Methods

to_string

to_string(): String

Returns the cookie as the value of a Set-Cookie field, such as id=7; Path=/; Max-Age=60; HttpOnly.

Returns

  • the field value

Panics

  • if name, value, path or domain has a character it may not have ("invalid cookie ..."), since it could split the field or add attributes

set_cookie

set_cookie(response: http.Response, cookie: Cookie)

Adds a Set-Cookie field for cookie to response.

Parameters

  • response — the response
  • cookie — the cookie to set

Panics

  • as Cookie.to_string does

parse_cookies

parse_cookies(header: String): Array<(String, String)>

Returns the names and values in a Cookie field, such as a=1; b="two", in order. Surrounding double quotes are removed from a value; nothing is decoded. A piece without = is skipped.

Parameters

  • header — the field's value
