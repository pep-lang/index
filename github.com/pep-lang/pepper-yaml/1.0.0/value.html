YamlValue: a YAML value of any kind, as the core schema reads it.

Source: value.pep

YamlValue

enum YamlValue

A YAML value: null, a boolean, an integer, a float, a string, a sequence or a mapping. yaml.parse makes one from text and to_string writes it back.

Look values up with value["key"] and value[index]. A lookup that finds nothing (a missing key, an index past the end, or a lookup on a value of another kind) gives Null rather than panicking, so lookups chain: root["server"]["port"]. Then read the value with an as_ method, which gives none when the value is of another kind, or match on its case.

A mapping's keys are strings: a key written as another scalar (1:, true:) is the text it was written as. A Mapping keeps its keys in the order they were written.

A Sequence or Mapping case holds its array or map by reference, so changing them through value[key] = ..., append or the map from as_mapping() changes every holder of the value. An alias (*name) in the text is the very value its anchor names, not a copy.

Example

import yaml;

var server = yaml.YamlValue.mapping();
server["host"] = yaml.YamlValue.String("localhost");
server["ports"] = yaml.YamlValue.sequence([yaml.YamlValue.Integer(80)]);
assert(server.to_string() == "host: localhost\nports:\n  - 80\n", "block style");
assert(server["ports"][0].as_int().value() == 80, "a lookup");
assert(server["missing"]["deeper"].is_null(), "lookups chain");

to_string

to_string(): String

Returns the value as a YAML document in block style: a mapping's members as key: value lines, a sequence's elements as - value lines, nested collections indented by two spaces, and a string with line breaks as a | literal block. Strings are quoted only when plain text would read back as something else.

Returns

  • the YAML text, ending with a line break

Example

import yaml;

var root = yaml.parse("name: demo\ntags: [a, b]\n").value();
assert(root.to_string() == "name: demo\ntags:\n  - a\n  - b\n", "block style");
