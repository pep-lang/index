yaml

YAML 1.2: parse text into a YamlValue, look values up and change them, write values back as YAML, edit a document keeping its comments and layout, and convert structs to YAML and back.

Bring it in with import yaml. Parsing follows YAML 1.2 with its core schema, so yes, no, on and off are strings, not booleans. It is safe for untrusted text: only the core schema's tags are read, aliases may not stand for more than a set number of nodes, and nesting is bounded. Errors carry a line and column, like a compiler's. Mappings keep their keys in the order they were written.

  • YamlValue: a value of any kind
  • parse, parse_all, YamlError, decode_text: reading
  • YamlValue.to_string, write_all: writing
  • parse_document, YamlDocument: changing a file people edit without losing its comments
  • encode, decode, to_yaml, from_yaml: struct conversion, with the attributes of the serialize module, as json converts structs

Example

import yaml;

main(): int {
    var parsed = yaml.parse("name: demo\nversion: 0.1.0\ntags: [cli, yaml]\n");
    if (parsed.is_err()) {
        print(parsed.error().to_string());
        return 1;
    }
    var root = parsed.value();
    assert(root["name"].as_string().value() == "demo", "a string");
    root["tags"].append(yaml.YamlValue.String("new"));
    print(root.to_string());
    return 0;
}

convert.pep

Struct conversion: encode and decode turn Pepper values into YAML text and back, through reflection, with no per-type code to write.

They convert as json's to_json and from_json do, through a json.JsonValue, so the rules and the serialize attributes ([Name], [Ignore], [Required], [Tag], [Untagged]) are the same in both formats: a property's key is its name as written, Optional<T> is the value or null, and a Result is a compile error.

to_yaml

to_yaml<T>(value: T): YamlValue

Converts value to a YamlValue, as json.to_json converts it to JSON: a struct's public properties become a mapping's members in declaration order, an Array a sequence, an enum case that carries no values its name.

Type parameters

  • T — the type of the value

Parameters

  • value — the value to convert

Returns

  • the value as YAML

Example

import yaml;

struct Point {
    var x: int;
    var y: int;
}

main(): int {
    var p = Point();
    p.x = 1;
    p.y = 2;
    assert(yaml.to_yaml(p)["y"].as_int().value() == 2, "a member");
    return 0;
}

import yaml;

from_yaml

from_yaml<T>(value: YamlValue, unknown_keys: json.UnknownKeys = json.UnknownKeys.Ignore): Result<T, YamlError>

Converts a YamlValue to a T, the reverse of to_yaml, as json.from_json converts JSON.

A struct is made with its constructor that takes no arguments, then each property found in the mapping is read in. A missing key leaves its property at its default, unless the property is marked [Required], which makes it an error. A key that names no property is skipped, or with unknown_keys = json.UnknownKeys.Reject is an error.

An error names where in the document it is, as a path from the root $ in its value_path and at the start of its message, and has no line or column, since there is no text: $.server.port: expected a number, found a string.

Type parameters

  • T — the type to convert to

Parameters

  • value — the YAML value
  • unknown_keys — what to do with a key that names no property

Returns

  • the converted value, or the first error

decode

decode<T>( text: String, unknown_keys: json.UnknownKeys = json.UnknownKeys.Ignore, path: String = "", merge_keys: bool = false ): Result<T, YamlError>

Parses a YAML document and converts it to a T: parse, then from_yaml.

Type parameters

  • T — the type to convert to

Parameters

  • text — the YAML text
  • unknown_keys — what to do with a key that names no property
  • path — the name of the text (a file name, say), which the error's to_string() puts first
  • merge_keys — whether a << key merges mappings, as parse says

Returns

  • the value, or the first error: a syntax error, or a conversion error with its path in the document; either has its line and column

Example

import serialize;
import yaml;

struct ServerConfig {
    var host: String;
    [Required]
    var port: int;
    var tags: Array<String>;
    var timeout: int?;
}

main(): int {
    var config = yaml.decode<ServerConfig>("host: a\nport: 80\ntags: [x]\n");
    assert(config.value().port == 80, "a number");
    assert(config.value().tags[0] == "x", "a sequence");
    assert(config.value().timeout.is_empty(), "a missing optional");

    var bad = yaml.decode<ServerConfig>("port: eighty\n", path = "server.yaml");
    assert(bad.error().to_string() == "server.yaml:1:7: error: $.port: expected a number, found a string", "where");
    return 0;
}

YamlDocument

struct YamlDocument

A YAML value with the comments and layout of the text it was read from, as parse_document makes it.

Each comment belongs to a value, by the value's path from the root $ ($.server.port, $.hosts[0]): the comment and blank lines before a key or - stay with its value, a comment at the end of a value's line stays on that line, and those after a collection's last entry, indented at least as far as its entries, stay at its end. to_string() writes them back in those places, along with how each value was written: key order, flow collections ([a, b]) or block ones, quoted, block (|, >) or plain scalars (0x1f stays 0x1f), and the indentation of nested mappings and of sequences under a key. So text read and written unchanged comes back as it was, or close to it: what is not kept is the spacing inside a line, comments inside a flow collection, anchors and aliases (each alias is written out in full), and % directives.

Change root freely. A comment or style whose value is gone (a removed key, a sequence shortened past it) is not written; one whose path names another value afterwards (an element shifted into its index) goes with that value. A value that changed is written in the default way for it.

To save the cost of keeping all this when only the values matter, use parse.

Example

import yaml;

var text = "# The server.\nserver:\n  port: 8080  # the default\n  hosts: [a, b]\n";
var document = yaml.parse_document(text).value();
document.root["server"]["port"] = yaml.YamlValue.Integer(9090);
assert(
    document.to_string() == "# The server.\nserver:\n  port: 9090 # the default\n  hosts: [a, b]\n",
    "the comments and the flow sequence stay"
);
assert(document.comments("$")[0] == "# The server.", "by path");

parse

parse( text: String, path: String = "", max_depth: ulong = 256, max_alias_nodes: ulong = 1000000, merge_keys: bool = false ): Result<YamlValue, YamlError>

Parses YAML 1.2 text holding one document into a YamlValue.

Plain scalars are read with the core schema: null, ~ and nothing are Null; true and false (also True, TRUE, ...) are booleans; 42, 0x2a and 0o52 are integers; 1.5, 1e3, .inf and .nan are floats; anything else, yes, no, on and off included, is a string. Quoted and block scalars (|, >) are strings.

Only the core schema's tags are read: !!str, !!int, !!float, !!bool, !!null, !!seq and !!map (and !, which makes a plain scalar a string). Any other tag is an error, so no text can ask for a type of its own to be made.

Anchors and aliases (&base, *base) are read, and an alias is the value its anchor names, shared rather than copied. So that a small text cannot stand for a huge value (the "billion laughs" attack), the nodes all aliases stand for, counted as if each were copied, may not pass max_alias_nodes.

The text must be valid UTF-8; a byte-order mark at the start is skipped (use decode_text for UTF-16). A mapping's keys must be scalars and must differ. YAML 1.1's merge key (<<: *base) is an ordinary key unless merge_keys is true.

With merge_keys, a plain << key merges the mapping it names, or each mapping of the list it names, into the mapping that holds it: the merged keys take the place of the << entry, keys the mapping sets itself win, and an earlier mapping of the list wins over a later one. A merged mapping is usually an alias, so its nodes count toward max_alias_nodes. A << naming anything else is an error.

Parameters

  • text — the YAML text
  • path — the name of the text (a file name, say), which the error's to_string() puts first
  • max_depth — how deeply collections may nest
  • max_alias_nodes — how many nodes the aliases may stand for in all
  • merge_keys — whether a << key merges mappings, as in YAML 1.1

Returns

  • the document's value (Null for text with no document), or an error naming the first problem and its line and column; text holding more than one document is an error (use parse_all)

Example

import yaml;

var parsed = yaml.parse("server:\n  port: 8080\n  debug: no\n");
assert(parsed.value()["server"]["port"].as_int().value() == 8080, "an integer");
assert(parsed.value()["server"]["debug"].as_string().value() == "no", "not a boolean");
var bad = yaml.parse("a: *missing", path = "config.yaml");
assert(bad.error().to_string() == "config.yaml:1:4: error: undefined alias 'missing'", "where");

parse_all

parse_all( text: String, path: String = "", max_depth: ulong = 256, max_alias_nodes: ulong = 1000000, merge_keys: bool = false ): Result<Array<YamlValue>, YamlError>

Parses YAML 1.2 text holding any number of documents, each started by --- or ended by ..., into one YamlValue each.

Each document is read as parse reads one, merge keys included; anchors and %TAG directives hold only in their own document.

Parameters

  • text — the YAML text
  • path — the name of the text (a file name, say), which the error's to_string() puts first
  • max_depth — how deeply collections may nest
  • max_alias_nodes — how many nodes the aliases of each document may stand for in all
  • merge_keys — whether a << key merges mappings, as in YAML 1.1

Returns

  • the documents in order (none for empty text), or an error naming the first problem and its line and column

Example

import yaml;

var documents = yaml.parse_all("---\nname: a\n---\nname: b\n").value();
assert(documents.count == 2, "two documents");
assert(documents[1]["name"].as_string().value() == "b", "the second");

decode_text

decode_text(bytes: u8[], path: String = ""): Result<String, YamlError>

Decodes the bytes of a YAML file into text for parse, in whichever encoding YAML allows they are: UTF-8, or UTF-16 in either byte order, told apart by a byte-order mark or, without one, by where the zero bytes of the first character are. A byte-order mark is dropped.

Parameters

  • bytes — the file's contents
  • path — the name of the text, which the error's to_string() puts first

Returns

  • the text, or an error when the bytes are not valid in their encoding or are UTF-32, which this package does not read

Example

import text;
import yaml;

var bytes = text.Utf16.encode("\u{feff}a: 1\n");
var decoded = yaml.decode_text(bytes).value();
assert(yaml.parse(decoded).value()["a"].as_int().value() == 1, "UTF-16");

YamlValue

enum YamlValue

A YAML value: null, a boolean, an integer, a float, a string, a sequence or a mapping. yaml.parse makes one from text and to_string writes it back.

Look values up with value["key"] and value[index]. A lookup that finds nothing (a missing key, an index past the end, or a lookup on a value of another kind) gives Null rather than panicking, so lookups chain: root["server"]["port"]. Then read the value with an as_ method, which gives none when the value is of another kind, or match on its case.

A mapping's keys are strings: a key written as another scalar (1:, true:) is the text it was written as. A Mapping keeps its keys in the order they were written.

A Sequence or Mapping case holds its array or map by reference, so changing them through value[key] = ..., append or the map from as_mapping() changes every holder of the value. An alias (*name) in the text is the very value its anchor names, not a copy.

Example

import yaml;

var server = yaml.YamlValue.mapping();
server["host"] = yaml.YamlValue.String("localhost");
server["ports"] = yaml.YamlValue.sequence([yaml.YamlValue.Integer(80)]);
assert(server.to_string() == "host: localhost\nports:\n  - 80\n", "block style");
assert(server["ports"][0].as_int().value() == 80, "a lookup");
assert(server["missing"]["deeper"].is_null(), "lookups chain");
