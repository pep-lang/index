yaml

convert.pep

Struct conversion: encode and decode turn Pepper values into YAML text and back, through reflection, with no per-type code to write.

They convert as json's to_json and from_json do, through a json.JsonValue, so the rules and the serialize attributes ([Name], [Ignore], [Required], [Tag], [Untagged]) are the same in both formats: a property's key is its name as written, Optional<T> is the value or null, and a Result is a compile error.

Source: convert.pep

to_yaml

to_yaml<T>(value: T): YamlValue

Converts value to a YamlValue, as json.to_json converts it to JSON: a struct's public properties become a mapping's members in declaration order, an Array a sequence, an enum case that carries no values its name.

Type parameters

  • T — the type of the value

Parameters

  • value — the value to convert

Returns

  • the value as YAML

Example

import yaml;

struct Point {
    var x: int;
    var y: int;
}

main(): int {
    var p = Point();
    p.x = 1;
    p.y = 2;
    assert(yaml.to_yaml(p)["y"].as_int().value() == 2, "a member");
    return 0;
}

encode

encode<T>(value: T): String

Writes value as a YAML document, converting it as to_yaml does.

Type parameters

  • T — the type of the value

Parameters

  • value — the value to write

Returns

  • the YAML text, ending with a line break

Example

import serialize;
import yaml;

struct ServerConfig {
    var host: String;
    var max_connections: int;
    [Name("tls")]
    var use_tls: bool;
    var tags: Array<String>;
}

main(): int {
    var config = ServerConfig();
    config.host = "localhost";
    config.max_connections = 16;
    config.tags = ["web"];
    var text = yaml.encode(config);
    assert(text == "host: localhost\nmax_connections: 16\ntls: false\ntags:\n  - web\n", "a document");
    return 0;
}

from_yaml

from_yaml<T>(value: YamlValue, unknown_keys: json.UnknownKeys = json.UnknownKeys.Ignore): Result<T, YamlError>

Converts a YamlValue to a T, the reverse of to_yaml, as json.from_json converts JSON.

A struct is made with its constructor that takes no arguments, then each property found in the mapping is read in. A missing key leaves its property at its default, unless the property is marked [Required], which makes it an error. A key that names no property is skipped, or with unknown_keys = json.UnknownKeys.Reject is an error.

An error names where in the document it is, as a path from the root $ in its value_path and at the start of its message, and has no line or column, since there is no text: $.server.port: expected a number, found a string.

Type parameters

  • T — the type to convert to

Parameters

  • value — the YAML value
  • unknown_keys — what to do with a key that names no property

Returns

  • the converted value, or the first error

decode

decode<T>( text: String, unknown_keys: json.UnknownKeys = json.UnknownKeys.Ignore, path: String = "", merge_keys: bool = false ): Result<T, YamlError>

Parses a YAML document and converts it to a T: parse, then from_yaml.

Type parameters

  • T — the type to convert to

Parameters

  • text — the YAML text
  • unknown_keys — what to do with a key that names no property
  • path — the name of the text (a file name, say), which the error's to_string() puts first
  • merge_keys — whether a << key merges mappings, as parse says

Returns

  • the value, or the first error: a syntax error, or a conversion error with its path in the document; either has its line and column

Example

import serialize;
import yaml;

struct ServerConfig {
    var host: String;
    [Required]
    var port: int;
    var tags: Array<String>;
    var timeout: int?;
}

main(): int {
    var config = yaml.decode<ServerConfig>("host: a\nport: 80\ntags: [x]\n");
    assert(config.value().port == 80, "a number");
    assert(config.value().tags[0] == "x", "a sequence");
    assert(config.value().timeout.is_empty(), "a missing optional");

    var bad = yaml.decode<ServerConfig>("port: eighty\n", path = "server.yaml");
    assert(bad.error().to_string() == "server.yaml:1:7: error: $.port: expected a number, found a string", "where");
    return 0;
}
