unicode

The Unicode algorithms the runtime leaves out, with Unicode 16.0 data​: normalization, grapheme and word segmentation, display width, and case folding.

Bring it in with import unicode.

  • normalize, nfc, nfd, nfkc, nfkd, is_normalized, Form: NFC, NFD, NFKC and NFKD (UAX #15)
  • graphemes, Graphemes: extended grapheme clusters (UAX #29)
  • words, Words: the pieces between word boundaries (UAX #29)
  • display_width, code_point_width: terminal columns, as wcwidth
  • case_fold, equals_ignoring_case: full case folding and caseless matching
  • UNICODE_VERSION: the version of the data

Example

import unicode;

main(): int {
    var word = "cafe\u{301}";
    assert(unicode.normalize(word) == "caf\u{E9}", "NFC composes the accent");
    assert(unicode.graphemes(word).to_array().count == 4, "four characters");
    assert(unicode.display_width("日本") == 4, "two wide characters");
    assert(unicode.equals_ignoring_case("Café", "CAFE\u{301}"), "a caseless match");
    return 0;
}

case_fold

case_fold(value: String): String

Returns value with full case folding (CaseFolding.txt's C and F mappings) applied: the form to compare text in without regard to case. Folding is not lowercasing for display: ß folds to ss, and the Cherokee letters fold to their uppercase forms.

ASCII text is folded by String.lower().

Parameters

  • value — the text to fold; it must be valid UTF-8

Returns

  • a new String, case-folded

Example

import unicode;

assert(unicode.case_fold("Straße") == "strasse", "ß folds to ss");
assert(unicode.case_fold("ΣΊΣΥΦΟΣ") == "σίσυφοσ", "every sigma folds to σ");

equals_ignoring_case

equals_ignoring_case(a: String, b: String): bool

Returns whether a and b are the same text without regard to case: Unicode's canonical caseless match, which compares NFD(case_fold(NFD(x))), so precomposed and decomposed accents match too.

Parameters

  • a — the first text
  • b — the second text

Returns

  • true when the two match without regard to case

Example

import unicode;

assert(unicode.equals_ignoring_case("STRASSE", "straße"), "ß matches ss");
assert(unicode.equals_ignoring_case("\u{C5}ngstr\u{F6}m", "a\u{30A}ngstro\u{308}m"), "accents match decomposed");

normalize.pep

Unicode normalization (UAX #15): NFC, NFD, NFKC and NFKD, and a quick check for text that is already normalized.

Source: normalize.pep

Form

enum Form

A Unicode normalization form.

Cases

Nfc

Nfc

Canonical composition: decomposes canonically, then composes again. The usual form for storing and comparing text.

Nfd

Nfd

Canonical decomposition: every precomposed character split into its base and combining marks, the marks in canonical order.

Nfkc

Nfkc

Compatibility composition: as Nfc, after also replacing compatibility characters (ligatures, full-width forms, superscripts) with their plain equivalents.

Nfkd

Nfkd

Compatibility decomposition: as Nfd, with compatibility characters replaced too.

normalize

normalize(value: String, form: Form = Form.Nfc): String

Returns value in normalization form form: nfc, nfd, nfkc or nfkd of it.

A program that calls only nfc (or nfd) does not carry the compatibility data that normalize brings in for Nfkc and Nfkd.

Parameters

  • value — the text to normalize; it must be valid UTF-8
  • form — the normalization form

Returns

  • a new String in that form

Example

import unicode;

var decomposed = "e\u{301}";   # e and a combining acute accent
assert(unicode.normalize(decomposed) == "\u{E9}", "NFC composes é");
assert(unicode.normalize("\u{E9}", unicode.Form.Nfd) == decomposed, "NFD splits it");
assert(unicode.normalize("\u{FB01}", unicode.Form.Nfkc) == "fi", "NFKC splits the ligature");

is_normalized

is_normalized(value: String, form: Form = Form.Nfc): bool

Returns whether value is in normalization form form, so that normalize(value, form) == value.

Decides most text with the UAX #15 quick check, which decodes it once; only text with a character that may or may not compose (NFC_QC or NFKC_QC Maybe) is normalized to compare.

Parameters

  • value — the text to check; it must be valid UTF-8
  • form — the normalization form

Returns

  • true when value is already in the form

Example

import unicode;

assert(unicode.is_normalized("caf\u{E9}"), "NFC");
assert(!unicode.is_normalized("cafe\u{301}"), "not NFC");
assert(unicode.is_normalized("cafe\u{301}", unicode.Form.Nfd), "NFD");

Graphemes

[Value] struct Graphemes

An Iterator<String> over the extended grapheme clusters of a String, each one a new String: what a reader sees as one character, such as a letter with its accents, a Hangul syllable written in jamo, a flag, or an emoji sequence joined by U+200D. Make it with graphemes: a default-constructed Graphemes() has no text to walk.

Example

import unicode;

var count = 0;
for (var cluster in unicode.graphemes("e\u{301}🇫🇷")) {
    count = count + 1;   # "é", then the flag
}
assert(count == 2, "two clusters");

graphemes(value: String): Graphemes

Returns an iterator over the extended grapheme clusters of value (UAX #29, Unicode 16), in order. Their texts joined give value back.

Words

[Value] struct Words

An Iterator<String> over the pieces of a String between UAX #29 word boundaries, each one a new String. Every piece is yielded: words and numbers, but also each run of spaces and each punctuation mark, so the pieces joined give the text back. Keep the ones that hold a letter or a digit to get only the words. Make it with words: a default-constructed Words() has no text to walk.

It reads the whole text's word properties when it is made.

Example

import unicode;

var pieces = unicode.words("can't stop").to_array();
assert(pieces.count == 3 && pieces[0] == "can't", "can't, space, stop");

code_point_width

code_point_width(cp: uint): ulong

Returns how many columns cp takes in a terminal, following wcwidth (Markus Kuhn's rules, with Unicode 16 data):

  • 2 for East Asian Wide and Fullwidth characters and for emoji with Emoji_Presentation;
  • 0 for combining marks (Mn, Me), format characters (Cf) except the soft hyphen U+00AD, U+200B ZERO WIDTH SPACE, Hangul medial vowels and final consonants (U+1160 to U+11FF, U+D7B0 to U+D7FF), and control characters, NUL included (where wcwidth gives -1);
  • 1 for everything else, East Asian Ambiguous characters and unassigned code points included.

Parameters

  • cp — the code point

Returns

  • 0, 1 or 2

Example

import unicode;

assert(unicode.code_point_width('a' as uint) == 1, "narrow");
assert(unicode.code_point_width(0x4E2D) == 2, "中 is wide");
assert(unicode.code_point_width(0x301) == 0, "a combining accent");

display_width

display_width(value: String): ulong

Returns how many columns value takes in a terminal: the sum of code_point_width over its code points, as wcswidth counts, so an emoji sequence joined by U+200D counts each emoji it joins. Controls, tabs and newlines count 0.

Parameters

  • value — the text to measure; it must be valid UTF-8

Returns

  • the width in columns

Example

import unicode;

assert(unicode.display_width("hello") == 5, "ASCII");
assert(unicode.display_width("日本語") == 6, "wide");
assert(unicode.display_width("e\u{301}") == 1, "the accent takes no column");
