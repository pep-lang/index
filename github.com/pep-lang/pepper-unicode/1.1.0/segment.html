Text segmentation (UAX #29): extended grapheme clusters, the user-perceived characters, and word boundaries.

Source: segment.pep

Graphemes

[Value] struct Graphemes

An Iterator<String> over the extended grapheme clusters of a String, each one a new String: what a reader sees as one character, such as a letter with its accents, a Hangul syllable written in jamo, a flag, or an emoji sequence joined by U+200D. Make it with graphemes: a default-constructed Graphemes() has no text to walk.

Example

import unicode;

var count = 0;
for (var cluster in unicode.graphemes("e\u{301}🇫🇷")) {
    count = count + 1;   # "é", then the flag
}
assert(count == 2, "two clusters");

graphemes

graphemes(value: String): Graphemes

Returns an iterator over the extended grapheme clusters of value (UAX #29, Unicode 16), in order. Their texts joined give value back.

Parameters

  • value — the text to split; it must be valid UTF-8

Returns

  • an iterator positioned before the first cluster

Example

import unicode;

var clusters = unicode.graphemes("ka\u{308}!").to_array();
assert(clusters.count == 3 && clusters[1] == "a\u{308}", "k, ä, !");

Words

[Value] struct Words

An Iterator<String> over the pieces of a String between UAX #29 word boundaries, each one a new String. Every piece is yielded: words and numbers, but also each run of spaces and each punctuation mark, so the pieces joined give the text back. Keep the ones that hold a letter or a digit to get only the words. Make it with words: a default-constructed Words() has no text to walk.

It reads the whole text's word properties when it is made.

Example

import unicode;

var pieces = unicode.words("can't stop").to_array();
assert(pieces.count == 3 && pieces[0] == "can't", "can't, space, stop");

words

words(value: String): Words

Returns an iterator over the pieces of value between word boundaries (UAX #29, Unicode 16), in order. The pieces joined give value back.

Parameters

  • value — the text to split; it must be valid UTF-8

Returns

  • an iterator positioned before the first piece

Example

import unicode;

var pieces = unicode.words("3.14 is π.").to_array();
# "3.14", " ", "is", " ", "π", "."
assert(pieces.count == 6 && pieces[0] == "3.14", "a number with its point");
