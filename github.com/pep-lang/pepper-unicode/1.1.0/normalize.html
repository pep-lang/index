unicode

normalize.pep

Unicode normalization (UAX #15): NFC, NFD, NFKC and NFKD, and a quick check for text that is already normalized.

Source: normalize.pep

Form

enum Form

A Unicode normalization form.

Cases

Nfc

Nfc

Canonical composition: decomposes canonically, then composes again. The usual form for storing and comparing text.

Nfd

Nfd

Canonical decomposition: every precomposed character split into its base and combining marks, the marks in canonical order.

Nfkc

Nfkc

Compatibility composition: as Nfc, after also replacing compatibility characters (ligatures, full-width forms, superscripts) with their plain equivalents.

Nfkd

Nfkd

Compatibility decomposition: as Nfd, with compatibility characters replaced too.

normalize

normalize(value: String, form: Form = Form.Nfc): String

Returns value in normalization form form: nfc, nfd, nfkc or nfkd of it.

A program that calls only nfc (or nfd) does not carry the compatibility data that normalize brings in for Nfkc and Nfkd.

Parameters

  • value — the text to normalize; it must be valid UTF-8
  • form — the normalization form

Returns

  • a new String in that form

Example

import unicode;

var decomposed = "e\u{301}";   # e and a combining acute accent
assert(unicode.normalize(decomposed) == "\u{E9}", "NFC composes é");
assert(unicode.normalize("\u{E9}", unicode.Form.Nfd) == decomposed, "NFD splits it");
assert(unicode.normalize("\u{FB01}", unicode.Form.Nfkc) == "fi", "NFKC splits the ligature");

nfc(value: String): String

Returns value in NFC: decomposed canonically, then composed again.

Text already in NFC, all-ASCII text included, is found so by a quick check that decodes it once, and copied.

is_normalized

is_normalized(value: String, form: Form = Form.Nfc): bool

Returns whether value is in normalization form form, so that normalize(value, form) == value.

Decides most text with the UAX #15 quick check, which decodes it once; only text with a character that may or may not compose (NFC_QC or NFKC_QC Maybe) is normalized to compare.

Parameters

  • value — the text to check; it must be valid UTF-8
  • form — the normalization form

Returns

  • true when value is already in the form

Example

import unicode;

assert(unicode.is_normalized("caf\u{E9}"), "NFC");
assert(!unicode.is_normalized("cafe\u{301}"), "not NFC");
assert(unicode.is_normalized("cafe\u{301}", unicode.Form.Nfd), "NFD");
