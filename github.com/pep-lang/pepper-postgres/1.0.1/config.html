Config: where a connection goes and how it logs in.

Source: config.pep

Config

struct Config

The settings of a connection: the server, the login, the database, and whether to use TLS.

Make one with the constructor and set fields, or parse a connection URL with parse.

Example

var config = postgres.Config("app", "secret");
config.host = "db.example.com";
config.database = "inventory";
config.tls = true;

Fields

host

var host: String

The server's host name or address.

port

var port: u16

The server's port.

user

var user: String

The user to log in as.

password

var password: String

The user's password; empty when the server asks for none.

database

var database: String

The database to connect to; empty for the one named after the user.

tls

var tls: bool

Whether to require TLS. The server's certificate is checked against the system's trusted roots (plus root_certificate) and must name host; the connection fails when the server does not offer TLS.

root_certificate

var root_certificate: String?

A PEM file of a further root certificate to trust, such as a private CA's.

max_notifications

var max_notifications: ulong

The most notifications a connection keeps until notifications() or wait_for_notification() takes them: 10,000 by default, and at least 1. Past it the oldest is dropped, and counted in Connection.dropped_notifications().

Constructor

Config()

construct(user: String, password: String = "")

Creates a config for localhost:5432 without TLS.

Parameters

  • user — the user to log in as
  • password — the user's password

Static methods

parse

static parse(url: String): PgResult<Config>

Parses a connection URL, postgres://user:password@host:port/database?sslmode=require, as libpq writes them (postgresql:// too). Every part but the host is optional, and percent-escapes are decoded.

sslmode require, verify-ca and verify-full set tls (which always verifies the certificate); disable, allow and prefer leave it off. sslrootcert sets root_certificate. Other parameters are ignored.

Parameters

  • url — the connection URL

Returns

  • the config, or an error with code 08000 when the URL is not a PostgreSQL URL

Example

var config = postgres.Config.parse("postgres://app:secret@localhost/inventory").value();
