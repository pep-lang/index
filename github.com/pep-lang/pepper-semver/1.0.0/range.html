range.pep

Version ranges and matching: VersionRange, Comparison and parse_range, which reads ranges the way Cargo does:

1.2, ^1.2     >=1.2.0, &lt;2.0.0     (the leftmost nonzero part stays)
0.4, ^0.4     >=0.4.0, &lt;0.5.0
^0.0.3        >=0.0.3, &lt;0.0.4
~1.2          >=1.2.0, &lt;1.3.0
~1            >=1.0.0, &lt;2.0.0
1.2.x, 1.2.*  >=1.2.0, &lt;1.3.0
=1.2.3        exactly 1.2.3
=1.2          >=1.2.0, &lt;1.3.0
>1.2          >=1.3.0
&lt;=1.2         &lt;1.3.0
>=1.0, &lt;2     both comparisons
*             any release

VersionRange

struct VersionRange

A version range: a version is in it when every comparison holds.

Fields

text

var text: String = ""

The range as it was written.

comparisons

var comparisons: Array<Comparison> = __null

The comparisons, all of which must hold; none for *.

Constructor

VersionRange()

construct()

Creates the range *, which every release matches.

Methods

matches

matches(candidate: Version): bool

Returns whether candidate is in the range.

A prerelease is in it only when a comparison names a prerelease of the same major.minor.patch, as Cargo and npm do, so ^1.2 never picks 1.3.0-beta but >=1.3.0-beta, <2 does.

Parameters

  • candidate — the version to test

Returns

  • true when every comparison holds for candidate

parse_range

parse_range(text: String): Result<VersionRange>

Parses a range: comparisons separated by commas, each an operator (^, ~, =, >, >=, <, <=, or none, which means ^) and a partial version (1, 1.2, 1.2.3, 1.2.x, 1.2.3-rc.1), or * (see the top of this page for what each means).

Parameters

  • text — the range

Returns

  • the range, or an error saying what is wrong

Example

var range = semver.parse_range(">=1.0, <2").value();
assert(range.matches(semver.parse("1.8.0").value()), "in range");
assert(!range.matches(semver.parse("2.0.0").value()), "the bound is excluded");
