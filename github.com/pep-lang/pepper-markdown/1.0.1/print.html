markdown

Markdown: CommonMark 0.31.2 and the GitHub Flavored Markdown extensions (tables, task lists, strikethrough, extended autolinks), parsed into a tree of Nodes and rendered as HTML.

Bring it in with import markdown. It is pure Pepper. Any text is Markdown, so nothing here fails; text is always escaped in the HTML, and Options(safe = true) also drops raw HTML and javascript: links, for Markdown from writers you do not trust.

  • to_html: Markdown to HTML in one step
  • parse, Node, NodeKind, Alignment: the tree, for other renderers or for reading a document's structure
  • Node.events, Event: a walk over the tree as enter and leave events
  • render_html: a tree to HTML
  • Options: GFM on or off, and safe mode

Example

import markdown;

main(): int {
    var html = markdown.to_html("| a | b |\n| - | - |\n| ~~1~~ | 2 |\n");
    assert(html.contains("<td><del>1</del></td>"), "a GFM table");
    print(markdown.to_html("Hello, *world*!\n"));   # <p>Hello, <em>world</em>!</p>
    return 0;
}

to_html

to_html(markdown: String, options: Options = Options()): String

Converts Markdown to HTML: render_html(parse(markdown, options), options).

Text is escaped, so <, & and " in it never become markup. Raw HTML passes through as the spec says (with GFM on, the tag filter escapes <script>, <iframe> and the like), unless options.safe is set, which drops it and empties dangerous link URLs.

Parameters

  • markdown — the text to convert
  • options — the extensions to use, and whether to make the HTML safe

Returns

  • the HTML, a line ending after each block

Example

import markdown;

main(): int {
    print(markdown.to_html("# Title\n\nSome *emphasis* and `code`.\n"));
    # <h1>Title</h1>
    # <p>Some <em>emphasis</em> and <code>code</code>.</p>
    var safe = markdown.Options(safe = true);
    assert(markdown.to_html("<b>hi</b> [x](javascript:alert(1))\n", safe) == "<p>hi <a href=\"\">x</a></p>\n", "no raw HTML");
    return 0;
}

Node

struct Node

A block or inline element of a parsed document.

One struct holds every kind; kind says which, and only the fields that kind describes are set (the others keep their defaults). A renderer of its own walks children recursively or uses events().

Example

import markdown;

main(): int {
    var doc = markdown.parse("# Hi *there*\n");
    var heading = doc.children[0];
    assert(heading.kind == markdown.NodeKind.Heading && heading.level == 1, "a level 1 heading");
    assert(heading.children[1].kind == markdown.NodeKind.Emphasis, "then emphasis");
    return 0;
}

events

events(): Array<Event>

Lists the steps of a depth-first walk over this node and its descendants: an entering event for each node, then its children's events, then a leaving event. A node with no children (a Text, say) has an entering event and a leaving one too.

Returns

  • the events, the first entering this node

Example

import markdown;

main(): int {
    var words = 0;
    for (var event in markdown.parse("a *b* c\n").events()) {
        if (event.entering && event.node.kind == markdown.NodeKind.Text) {
            words += 1;
        }
    }
    assert(words == 3, "three text nodes");
    return 0;
}

parse

parse(markdown: String, options: Options = Options()): Node

Parses markdown into a tree: a Document node whose children are the top-level blocks. Any text is Markdown, so parsing never fails.

Link reference definitions are resolved, so links that use them carry their destination; the definitions themselves leave no node.

Parameters

  • markdown — the text to parse
  • options — the extensions to use

Returns

  • the document's root

Example

import markdown;

main(): int {
    var doc = markdown.parse("- [x] done\n- [ ] to do\n");
    var list = doc.children[0];
    assert(list.kind == markdown.NodeKind.List && list.tight, "a tight list");
    assert(list.children[0].task && list.children[0].checked, "a checked task");
    return 0;
}
