markdown

parse.pep

Parsing: Options, and parse, which reads Markdown into a tree of Nodes. The block structure is read line by line, as the CommonMark spec describes, and then each paragraph's, heading's and table cell's text is parsed into inlines.

Source: parse.pep

Options

struct Options

What parse, render_html and to_html do beyond CommonMark.

Fields

gfm

var gfm: bool

Whether the GitHub Flavored Markdown extensions are on: tables, task list items, strikethrough, extended autolinks (www., https://, emails), and the tag filter, which escapes the < of tags such as <script> and <iframe> in raw HTML.

safe

var safe: bool

Whether the HTML is safe to show from an untrusted writer: raw HTML is dropped, and a link or image to a javascript:, vbscript:, file: or (other than an image's) data: URL gets an empty URL.

Constructor

Options()

construct(gfm: bool = true, safe: bool = false)

Makes options.

Parameters

  • gfm — whether the GFM extensions are on
  • safe — whether raw HTML and dangerous URLs are dropped

parse

parse(markdown: String, options: Options = Options()): Node

Parses markdown into a tree: a Document node whose children are the top-level blocks. Any text is Markdown, so parsing never fails.

Link reference definitions are resolved, so links that use them carry their destination; the definitions themselves leave no node.

Parameters

  • markdown — the text to parse
  • options — the extensions to use

Returns

  • the document's root

Example

import markdown;

main(): int {
    var doc = markdown.parse("- [x] done\n- [ ] to do\n");
    var list = doc.children[0];
    assert(list.kind == markdown.NodeKind.List && list.tight, "a tight list");
    assert(list.children[0].task && list.children[0].checked, "a checked task");
    return 0;
}
