Reading CSV: Reader, which reads records from a stream as they are asked for; parse, which reads a whole text; and CsvError, what they report when the text is not CSV.

Source: read.pep

CsvError

struct CsvError

What reading reports when the text is not CSV, and what Reader.read and decode report when a field does not fit its property: what is wrong, and the line and column where it is.

to_string() renders it like a compiler error: people.csv:4:12: error: unterminated quoted field.

Fields

message

var message: String

What is wrong, worded like a compiler error (expected ',' or a line break after the closing '"').

path

var path: String

The path given to the reader, which names the text in to_string(); empty when none was given.

line

var line: ulong

The line of the error, from 1; 0 for an error with no place in the text, such as a failed read of the stream.

column

var column: ulong

The column of the error, from 1, counting bytes as clang does; 0 when line is.

Constructor

Creates an error.

Parameters

  • message — what is wrong
  • path — the name of the text, or empty
  • line — the line of the error, from 1
  • column — the column of the error, from 1

Methods

Returns the error as a compiler prints one: path:line:column: error: message, without the path: when there is no path and without line:column: when line is 0.

Returns

  • the rendered error

Reader

struct Reader

Reads CSV records from a stream, one at a time, so a large file is never held whole.

The format is RFC 4180's, read strictly: a field that holds the delimiter, a " or a line break is quoted, and a " inside it is doubled ("say ""hi"""). A record ends at \n or \r\n; a \r on its own is part of a field. A UTF-8 byte-order mark at the start is skipped, and blank lines are skipped, so a file that ends with a line break has no empty record after it. Anything else is an error that names its line and column: a " inside an unquoted field, text after a closing quote, a quoted field that never closes, or a field that is not UTF-8. The first error ends the reading.

Records may have different numbers of fields; read is what checks them against the header.

Example

import csv;
import io;

main(): int {
    var reader = csv.Reader(io.ByteReader("name,note\nada,\"says \"\"hi\"\"\"\n".bytes()));
    for (var record in reader) {
        if (record.is_err()) {
            print(record.error().to_string());
            return 1;
        }
        print(record.value()[1]);   # note, then: says "hi"
    }
    return 0;
}

Fields

path

var path: String

The name of the text, which errors carry; empty when none was given.

header

var header: Array<String>

The names of the header record, which the first read reads; empty until then.

line

var line: ulong

The line of the first field of the record read last, from 1.

Constructor

Reader()

construct(source: io.Reader, delimiter: String = ",", path: String = "", max_record_bytes: ulong = 16777216)

Makes a reader of the records of source, from what it reads next.

Parameters

  • source — the stream to read, such as an io.File, or an io.ByteReader over text in memory
  • delimiter — the one-byte text between fields: ",", "\t", ";"
  • path — the name of the text (a file name, say), which errors put first
  • max_record_bytes — the most bytes one record's fields may hold; a longer record is an error, so a quote that never closes cannot fill memory

Panics

  • if delimiter is not one byte, or is ", \r or \n ("csv: the delimiter must be one byte other than '"', '\r' and '\n'")

Methods

read

read<T>(): Result<T?, CsvError>

Reads the next record into a T, a struct, matching the header's names to its properties as decode does. The first call reads the header record first, into header.

A column that names no property is skipped; the other read can reject it instead.

Type parameters

  • T — the struct to read into

Returns

  • the value, none at the end of the stream, or the first error, at the line and column of the field it is about

next

next(): bool

Moves to the next record, so a for loop reads the records in turn.

Returns

  • true if there is a current element (a record, or the error that ends the reading), false at the end of the stream

current

Returns the element the last successful next() moved to.

Returns

  • the current record, or the error that ended the reading

Panics

parse

parse(text: String, delimiter: String = ",", path: String = ""): Result<Array<Array<String>>, CsvError>

Reads every record of a CSV text, as Reader reads them.

Parameters

  • text — the CSV text
  • delimiter — the one-byte text between fields: ",", "\t", ";"
  • path — the name of the text (a file name, say), which errors put first

Returns

  • the records in order (none for empty text), or the first error

Panics

  • if delimiter is not one byte, or is ", \r or \n

Example

import csv;

main(): int {
    var rows = csv.parse("a;b\n1;\"x;y\"\n", delimiter = ";").value();
    assert(rows[1][1] == "x;y", "a quoted delimiter");
    var bad = csv.parse("a,\"b\n", path = "bad.csv");
    assert(bad.error().to_string() == "bad.csv:1:3: error: unterminated quoted field", "where");
    return 0;
}
