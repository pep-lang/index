CSV (RFC 4180): streaming reader, writer, and struct conversion

Pages

  • csv: CSV (RFC 4180): read records from a stream or a text, write them back, and convert structs to records and back.
  • convert.pep: Struct conversion: decode reads CSV records into structs and encode writes structs as CSV records, through reflection, with no per-type code to write.
  • read.pep: Reading CSV: Reader, which reads records from a stream as they are asked for; parse, which reads a whole text; and CsvError, what they report when the text is not CSV.
  • write.pep: Writing CSV: Writer, which writes records to a stream, and write_all, which writes records into text.
