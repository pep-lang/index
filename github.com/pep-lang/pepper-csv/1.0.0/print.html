csv

CSV (RFC 4180): read records from a stream or a text, write them back, and convert structs to records and back.

Bring it in with import csv. Reading is strict and safe for untrusted text: a malformed record is an error with its line and column, like a compiler's, and a record may not pass a set size, so a quote that never closes cannot fill memory. A Reader reads a record at a time, so a large file is never held whole.

  • Reader, parse, CsvError: reading
  • Writer, write_all: writing
  • decode, encode, Reader.read, Writer.write: struct conversion, with the attributes of the serialize module, as json converts structs

Example

import csv;

main(): int {
    var parsed = csv.parse("name,tags\nada,\"cli, csv\"\n", path = "people.csv");
    if (parsed.is_err()) {
        print(parsed.error().to_string());
        return 1;
    }
    var rows = parsed.value();
    assert(rows[1][1] == "cli, csv", "a quoted field");
    rows[1][0] = "bob";
    print(csv.write_all(rows));
    return 0;
}

convert.pep

Struct conversion: decode reads CSV records into structs and encode writes structs as CSV records, through reflection, with no per-type code to write.

A record is a struct; the header names its properties. Conversion goes through json's, so the serialize attributes ([Name], [Ignore], [Required]) work as they do for json and toml.

Source: convert.pep

decode

decode<T>( text: String, delimiter: String = ",", path: String = "", unknown_keys: json.UnknownKeys = json.UnknownKeys.Ignore ): Result<Array<T>, CsvError>

Reads every record of a CSV text into a T, a struct, matching the header record's names to its properties.

A property takes its column from [Name("column")] when it has one, and is skipped when marked [Ignore]. A String property takes the field as it is, even empty. For any other property an empty field counts as missing, which leaves the property at its default, makes an Optional (String? included) empty, and is an error for a [Required] one; otherwise a String? takes the field as it is, and the rest read it as a JSON value (42, 2.5, true) or, failing that, as a string, so an enum takes a case's name. A column that names no property is skipped, or with unknown_keys = json.UnknownKeys.Reject is an error.

Every record must have as many fields as the header, and the header may not name a column twice.

Type parameters

  • T — the struct to read into

Parameters

  • text — the CSV text, its first record the header
  • delimiter — the one-byte text between fields: ",", "\t", ";"
  • path — the name of the text (a file name, say), which errors put first
  • unknown_keys — what to do with a column that names no property

Returns

  • the values in order, or the first error, at the line and column of the field it is about

Panics

  • if delimiter is not one byte, or is ", \r or \n

Example

import csv;
import serialize;

struct Person {
    [Required]
    var name: String;
    var age: int;
    [Name("e-mail")]
    var email: String?;
}

main(): int {
    var people = csv.decode<Person>("name,age,e-mail\nada,36,ada@example.com\nbob,,\n").value();
    assert(people[0].age == 36, "a number");
    assert(people[1].email.is_empty(), "an empty field");

    var bad = csv.decode<Person>("name,age\nada,old\n", path = "people.csv");
    assert(bad.error().to_string() == "people.csv:2:5: error: column 'age': expected a number, found a string", "where");
    return 0;
}

encode

encode<T>(values: Array<T>, delimiter: String = ",", line_ending: String = "\n"): String

Writes values, structs, as CSV: a header record of their property names, then one record per value, as Writer.write writes them.

Type parameters

  • T — the struct to write

Parameters

  • values — the values to write
  • delimiter — the one-byte text between fields
  • line_ending — the text after each record: "\n", or "\r\n" as RFC 4180 says

Returns

  • the CSV text; empty when values is

Panics

  • if delimiter is not one byte, or is ", \r or \n

Example

import csv;

struct Point {
    var x: int;
    var label: String;
}

main(): int {
    var p = Point();
    p.x = 1;
    p.label = "a, b";
    assert(csv.encode([p]) == "x,label\n1,\"a, b\"\n", "a header and a record");
    return 0;
}

CsvError

struct CsvError

What reading reports when the text is not CSV, and what Reader.read and decode report when a field does not fit its property: what is wrong, and the line and column where it is.

to_string() renders it like a compiler error: people.csv:4:12: error: unterminated quoted field.

Fields

message

var message: String

What is wrong, worded like a compiler error (expected ',' or a line break after the closing '"').

path

var path: String

The path given to the reader, which names the text in to_string(); empty when none was given.

line

var line: ulong

The line of the error, from 1; 0 for an error with no place in the text, such as a failed read of the stream.

column

var column: ulong

The column of the error, from 1, counting bytes as clang does; 0 when line is.

Reader

struct Reader

Reads CSV records from a stream, one at a time, so a large file is never held whole.

The format is RFC 4180's, read strictly: a field that holds the delimiter, a " or a line break is quoted, and a " inside it is doubled ("say ""hi"""). A record ends at \n or \r\n; a \r on its own is part of a field. A UTF-8 byte-order mark at the start is skipped, and blank lines are skipped, so a file that ends with a line break has no empty record after it. Anything else is an error that names its line and column: a " inside an unquoted field, text after a closing quote, a quoted field that never closes, or a field that is not UTF-8. The first error ends the reading.

Records may have different numbers of fields; read is what checks them against the header.

Example

import csv;
import io;

main(): int {
    var reader = csv.Reader(io.ByteReader("name,note\nada,\"says \"\"hi\"\"\"\n".bytes()));
    for (var record in reader) {
        if (record.is_err()) {
            print(record.error().to_string());
            return 1;
        }
        print(record.value()[1]);   # note, then: says "hi"
    }
    return 0;
}

Fields

path

var path: String

The name of the text, which errors carry; empty when none was given.

header

var header: Array<String>

The names of the header record, which the first read reads; empty until then.

line

var line: ulong

The line of the first field of the record read last, from 1.

Example

import csv;

main(): int {
    var rows = csv.parse("a;b\n1;\"x;y\"\n", delimiter = ";").value();
    assert(rows[1][1] == "x;y", "a quoted delimiter");
    var bad = csv.parse("a,\"b\n", path = "bad.csv");
    assert(bad.error().to_string() == "bad.csv:1:3: error: unterminated quoted field", "where");
    return 0;
}

Writer

struct Writer

Writes CSV records to a stream.

A field is quoted only when it must be: when it holds the delimiter, a ", \r or \n, or when it is a record's only field and empty (which would otherwise be a blank line, which a reader skips). A " inside a quoted field is doubled. What it writes, Reader reads back as it was.

Example

import csv;
import io;

main(): int {
    var out = io.ByteWriter();
    var writer = csv.Writer(out);
    writer.write_row(["name", "note"]);
    writer.write_row(["ada", "says \"hi\""]);
    assert(out.bytes == "name,note\nada,\"says \"\"hi\"\"\"\n".bytes(), "quoted where needed");
    return 0;
}

write

write<T>(value: T): Result<void, io.IoError>

Writes value, a struct, as a record of its public properties, in the order they are declared. The first call writes a header record of their names first.

Properties convert as json.to_json converts them, with the serialize attributes: [Name("column")] names a column and [Ignore] leaves a property out. A string is written as it is, an empty Optional as an empty field, and anything else as its JSON text (42, true), so decode reads it back.

Parameters

  • value — the value to write

Returns

  • an Ok result once the record is written; an error when the stream fails
