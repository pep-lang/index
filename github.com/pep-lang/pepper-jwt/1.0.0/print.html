jwt

JSON Web Tokens (RFC 7519): sign and verify JWS compact tokens (RFC 7515) with HS256 or EdDSA (Ed25519, RFC 8037), and validate their claims.

Bring it in with import jwt. Ed25519 comes from the crypto package, so the program links libsodium; HMAC-SHA-256 comes from the runtime's digest.

  • Key: a key for one algorithm, from a secret, a crypto key or a JWK
  • sign, verify: JWTs, with claims as json.JsonValue or a struct
  • Validation: the exp, nbf, iat, iss and aud checks
  • sign_jws, verify_jws: JWS of any payload

Example

import json;
import jwt;

main(): int {
    var key = jwt.Key.hs256("a secret of at least thirty-two bytes".bytes()).value();
    var claims = json.JsonValue.object();
    claims["sub"] = json.JsonValue.String("ada");
    claims["exp"] = json.JsonValue.Integer(4000000000);
    var token = jwt.sign(claims, key).value();
    var checked = jwt.verify<json.JsonValue>(token, key);
    print(checked.value()["sub"].as_string().value());   # ada
    return 0;
}

Key

struct Key

A key for one algorithm: HS256 (an HMAC-SHA-256 secret) or EdDSA (an Ed25519 key).

A key only signs and checks tokens of its own algorithm, so a token cannot choose how it is checked: an HS256 token never verifies against an Ed25519 key, nor an EdDSA token against an HMAC secret.

Example

import crypto;
import jwt;

main(): int {
    var hmac = jwt.Key.hs256("a secret of at least thirty-two bytes".bytes()).value();
    var ed = jwt.Key.ed25519(crypto.SigningKey.generate());
    print(hmac.algorithm());   # HS256
    print(ed.algorithm());   # EdDSA
    return 0;
}

from_jwk

static from_jwk(text: String): Result<Key>

Reads a key from a JSON Web Key (RFC 7517): an oct key (RFC 7518, section 6.4) for HS256, or an OKP key with crv Ed25519 (RFC 8037), which signs when it holds the secret d and only checks when it holds just x.

Parameters

  • text — the JWK, a JSON object

Returns

  • the key, or an error when the text is not a JWK, names another key type, curve or alg, or its key bytes are invalid (an Ed25519 d whose public key is not x, too short a secret)

Example

import jwt;

var key = jwt.Key.from_jwk("{\"kty\":\"OKP\",\"crv\":\"Ed25519\",\"x\":\"11qYAYKxCrfVS_7TyWQHOg7hcvPapiMlrwIaaPcHURo\"}").value();
assert(key.algorithm() == "EdDSA", "an Ed25519 public key");

sign

sign<T>(claims: T, key: Key): Result<String>

Signs claims as a JWT: the header {"alg":...,"typ":"JWT"} and the claims as JSON, signed with key.

Type parameters

  • T — the claims' type: a json.JsonValue object, or a struct that json.to_json converts ([Name] and [Ignore] apply)

Parameters

  • claims — the claims, such as sub, exp and the application's own
  • key — the key to sign with

Returns

  • the token, or an error when key only holds a public key

Example

import json;
import jwt;

var key = jwt.Key.hs256("a secret of at least thirty-two bytes".bytes()).value();
var claims = json.JsonValue.object();
claims["sub"] = json.JsonValue.String("ada");
var token = jwt.sign(claims, key).value();

verify

verify<T>(token: String, key: Key, validation: Validation = Validation()): Result<T>

Checks a JWT's signature with key, then its claims with validation, and returns the claims.

The header's alg must be key's algorithm: none and every other algorithm are rejected, so a token cannot pick a weaker check or use a public key as an HMAC secret. A header with crit is rejected, as this package understands no extensions.

Type parameters

  • T — the claims' type: json.JsonValue, or a struct that json.from_json fills

Parameters

  • token — the token, in compact form
  • key — the key to check with
  • validation — the claims checks; by default exp is required and checked against the system clock

Returns

  • the claims, or an error saying why the token was rejected: malformed, wrong algorithm, bad signature, a time or issuer or audience check that failed, or claims that do not convert to T

Example

import json;
import jwt;

var key = jwt.Key.hs256("a secret of at least thirty-two bytes".bytes()).value();
var claims = json.JsonValue.object();
claims["sub"] = json.JsonValue.String("ada");
claims["exp"] = json.JsonValue.Integer(2000000000);
var token = jwt.sign(claims, key).value();
var checked = jwt.verify<json.JsonValue>(token, key, jwt.Validation().at(1900000000));
assert(checked.value()["sub"].as_string().value() == "ada", "the claims");

verify_jws

verify_jws(token: String, key: Key): Result<u8[]>

Checks a JWS in compact form with key and returns its payload. It makes the same header checks as verify but none of the claims.

Parameters

  • token — the JWS, three base64url parts joined by .
  • key — the key to check with

Returns

  • the payload, or an error when the token is malformed, its alg is not key's, it has crit, or the signature is wrong

Validation

struct Validation

What verify checks in a verified token's claims: the times exp, nbf and iat, and, when asked, the issuer iss and audience aud.

By default a token must carry exp and be inside its times, with no leeway, against the system clock. A claim set to null counts as absent. Set options by chaining.

Example

import jwt;

var checks = jwt.Validation().leeway(30).issuer("https://auth.example.com").audience("api");

Validation()
