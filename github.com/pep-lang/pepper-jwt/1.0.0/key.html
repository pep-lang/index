key.pep

Keys: Key holds the secret or key pair a token is signed or checked with, and fixes the one algorithm it may be used for.

Source: key.pep

Key

struct Key

A key for one algorithm: HS256 (an HMAC-SHA-256 secret) or EdDSA (an Ed25519 key).

A key only signs and checks tokens of its own algorithm, so a token cannot choose how it is checked: an HS256 token never verifies against an Ed25519 key, nor an EdDSA token against an HMAC secret.

Example

import crypto;
import jwt;

main(): int {
    var hmac = jwt.Key.hs256("a secret of at least thirty-two bytes".bytes()).value();
    var ed = jwt.Key.ed25519(crypto.SigningKey.generate());
    print(hmac.algorithm());   # HS256
    print(ed.algorithm());   # EdDSA
    return 0;
}

Constructor

Key()

construct()

Makes a blank key, which has no algorithm: it signs nothing and verifies no token. Use hs256, ed25519, ed25519_public or from_jwk instead.

Static methods

hs256

static hs256(secret: u8[]): Result<Key>

Makes an HS256 key from a shared secret, which both signs and checks.

Parameters

  • secret — the secret, at least 32 bytes (RFC 7518 forbids a shorter one); the key copies it

Returns

  • the key, or an error when secret is shorter than 32 bytes

ed25519

static ed25519(key: crypto.SigningKey): Key

Makes an EdDSA key that signs with key and checks with its public half.

Parameters

  • key — the Ed25519 secret key

Returns

  • the key

ed25519_public

static ed25519_public(key: crypto.VerifyingKey): Key

Makes an EdDSA key that only checks tokens, from an Ed25519 public key; signing with it fails.

Parameters

  • key — the Ed25519 public key

Returns

  • the key

from_jwk

static from_jwk(text: String): Result<Key>

Reads a key from a JSON Web Key (RFC 7517): an oct key (RFC 7518, section 6.4) for HS256, or an OKP key with crv Ed25519 (RFC 8037), which signs when it holds the secret d and only checks when it holds just x.

Parameters

  • text — the JWK, a JSON object

Returns

  • the key, or an error when the text is not a JWK, names another key type, curve or alg, or its key bytes are invalid (an Ed25519 d whose public key is not x, too short a secret)

Example

import jwt;

var key = jwt.Key.from_jwk("{\"kty\":\"OKP\",\"crv\":\"Ed25519\",\"x\":\"11qYAYKxCrfVS_7TyWQHOg7hcvPapiMlrwIaaPcHURo\"}").value();
assert(key.algorithm() == "EdDSA", "an Ed25519 public key");
