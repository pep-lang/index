jwt

token.pep

Tokens: sign and verify for JWTs (RFC 7519), and sign_jws and verify_jws for JWS compact serialization (RFC 7515) of any payload.

Source: token.pep

sign

sign<T>(claims: T, key: Key): Result<String>

Signs claims as a JWT: the header {"alg":...,"typ":"JWT"} and the claims as JSON, signed with key.

Type parameters

  • T — the claims' type: a json.JsonValue object, or a struct that json.to_json converts ([Name] and [Ignore] apply)

Parameters

  • claims — the claims, such as sub, exp and the application's own
  • key — the key to sign with

Returns

  • the token, or an error when key only holds a public key

Example

import json;
import jwt;

var key = jwt.Key.hs256("a secret of at least thirty-two bytes".bytes()).value();
var claims = json.JsonValue.object();
claims["sub"] = json.JsonValue.String("ada");
var token = jwt.sign(claims, key).value();

verify

verify<T>(token: String, key: Key, validation: Validation = Validation()): Result<T>

Checks a JWT's signature with key, then its claims with validation, and returns the claims.

The header's alg must be key's algorithm: none and every other algorithm are rejected, so a token cannot pick a weaker check or use a public key as an HMAC secret. A header with crit is rejected, as this package understands no extensions.

Type parameters

  • T — the claims' type: json.JsonValue, or a struct that json.from_json fills

Parameters

  • token — the token, in compact form
  • key — the key to check with
  • validation — the claims checks; by default exp is required and checked against the system clock

Returns

  • the claims, or an error saying why the token was rejected: malformed, wrong algorithm, bad signature, a time or issuer or audience check that failed, or claims that do not convert to T

Example

import json;
import jwt;

var key = jwt.Key.hs256("a secret of at least thirty-two bytes".bytes()).value();
var claims = json.JsonValue.object();
claims["sub"] = json.JsonValue.String("ada");
claims["exp"] = json.JsonValue.Integer(2000000000);
var token = jwt.sign(claims, key).value();
var checked = jwt.verify<json.JsonValue>(token, key, jwt.Validation().at(1900000000));
assert(checked.value()["sub"].as_string().value() == "ada", "the claims");

sign_jws

sign_jws(payload: u8[], key: Key): Result<String>

Signs payload as a JWS in compact form, with the header {"alg":...} naming key's algorithm.

Parameters

  • payload — the bytes to sign, which need not be JSON
  • key — the key to sign with

Returns

  • the JWS, or an error when key only holds a public key

verify_jws

verify_jws(token: String, key: Key): Result<u8[]>

Checks a JWS in compact form with key and returns its payload. It makes the same header checks as verify but none of the claims.

Parameters

  • token — the JWS, three base64url parts joined by .
  • key — the key to check with

Returns

  • the payload, or an error when the token is malformed, its alg is not key's, it has crit, or the signature is wrong
