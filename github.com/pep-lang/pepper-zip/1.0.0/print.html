zip

Zip archives: list, read and extract the entries of a .zip file, or write one.

Bring it in with import zip. Entries are stored or compressed with DEFLATE (from the runtime's compress module); archives and entries past 4 GiB use ZIP64. Entries compressed another way, or encrypted, are listed but reading one is an error naming the entry and the method. Extracting checks every name, so an archive cannot write outside the target directory. Errors name the archive and the entry (release.zip: entry 'lib/a.pep': CRC mismatch), and a damaged archive is an io.IoError whose is_invalid_input() holds.

  • Archive and EntryReader: reading
  • Writer: writing
  • Entry and Method: what an entry is

Example

import zip;

main(): int {
    var writer = zip.Writer.create("bundle.zip").value();
    writer.add("version.txt", "1.0.0".bytes()).value();
    writer.add_directory("docs").value();
    writer.finish().value();

    var archive = zip.Archive.open("bundle.zip").value();
    for (var entry in archive.entries()) {
        print($"{entry.name}: {entry.size} bytes");
    }
    var version = archive.read(archive.find("version.txt").value()).value();
    assert(version == "1.0.0".bytes(), "the contents");
    archive.extract_all("out").value();
    archive.close();
    return 0;
}

Entry and Method: what the central directory says about each file in an archive, and the helpers the reader and writer share.

Source: entry.pep

Method

enum Method

How an entry's contents are stored.

Cases

Stored

Stored

Stored as they are, uncompressed (method 0).

Deflate

Deflate

Compressed with DEFLATE (method 8), as nearly every zip tool writes.

Other

Other

Any other method, such as bzip2, LZMA or zstd: the entry is listed, but reading it is an error naming the method. Entry.method_code holds the number.

Entry

struct Entry

One entry of a zip archive: a file or directory, as the central directory describes it, without its contents.

Example

import zip;

var entry = zip.Entry("bin/run.sh");
entry.mode = 493;   # octal 755: rwxr-xr-x
entry.method = zip.Method.Stored;

EntryReader

struct EntryReader

Reads one entry's contents as a stream, decompressing them as they are read, so a large entry need not be in memory. It is an io.Reader.

At the end of the contents it checks their length and CRC-32 against the central directory: a mismatch is an is_invalid_input() error naming the archive and the entry (release.zip: entry 'lib/a.pep': CRC mismatch).

Example

import io;
import zip;

var archive = zip.Archive.open("logs.zip").value();
var reader = archive.open_entry(archive.find("today.log").value()).value();
for (var line in reader.lines()) {
    print(line.value());
}

Archive

struct Archive

A zip archive opened for reading: its entries, listed from the central directory when it is opened, and their contents, read on demand.

It reads stored and DEFLATE entries, ZIP64 archives (over 4 GiB, or over 65,535 entries), names in UTF-8 or code page 437, and archives with data before them, such as self-extracting programs. Entries compressed another way (bzip2, LZMA, zstd) or encrypted are listed, and reading one is an error naming it and the method, rather than the whole archive failing. Archives split across several files are not supported.

Every error names the archive, and the entry when there is one (release.zip: entry 'lib/a.pep': CRC mismatch); a damaged archive is an is_invalid_input() error.

Example

import zip;

main(): int {
    var opened = zip.Archive.open("release.zip");
    if (opened.is_err()) {
        print(opened.error().message);
        return 1;
    }
    var archive = opened.value();
    for (var entry in archive.entries()) {
        print($"{entry.name}: {entry.size} bytes");
    }
    archive.extract_all("out").value();
    return 0;
}

extract_all

extract_all(target: io.Path, strip_components: ulong = 0): io.IoResult<void>

Extracts every entry into the directory target, creating it and the directories the entries need, and checking each entry's CRC-32.

Every entry's name is checked with archive.safe_components before anything is written, so that no archive can write outside target ("zip slip"): an absolute path, a .. component, a \ or a : (a Windows drive) is an is_invalid_input() error. Files are written, replacing a file already there; symbolic links are skipped, as are permission bits and modification times.

Parameters

  • target — the directory to extract into
  • strip_components — how many leading path components to drop from each entry, as tar's --strip-components does; an entry with no components left is skipped

Returns

  • an Ok result once every entry is extracted; an is_invalid_input() error for an unsafe name or a damaged entry, or the error of a file that could not be written

close

close(): io.IoResult<void>

Closes the archive's file. Reading entries afterwards fails; an archive read from memory has nothing to close.

Returns

  • an Ok result; the error closing the file

Writer: writing a zip archive to a file or any stream.

Source: writer.pep

Writer

struct Writer

Writes a zip archive: each add writes one entry's local header and contents, and finish() writes the central directory that lists them.

Each entry is stored or compressed with DEFLATE, as its method says; an entry from memory that DEFLATE would not make smaller is stored instead. Names are written in UTF-8, with the flag that says so when they are not ASCII, and each entry carries its modification time to the second (the Unix extended timestamp) besides the format's two-second local time. ZIP64 records are added where an entry, an offset or the entry count needs them, so archives and entries may pass 4 GiB and 65,535 entries.

Entries from a stream (add_file, add_stream) are written as they are read, with their sizes and CRC-32 in a data descriptor after the contents, so the sink need not seek and the file need not fit in memory. Nothing is written in the background: errors come back from the call that hit them, and an archive whose finish() was not reached is incomplete.

Example

import zip;

main(): int {
    var writer = zip.Writer.create("bundle.zip").value();
    writer.add_file("docs/readme.md", "readme.md").value();
    writer.add("version.txt", "1.0.0".bytes()).value();
    writer.finish().value();
    return 0;
}

add_stream

add_stream(entry: Entry, source: io.Reader): io.IoResult<void>

Adds an entry with the header fields of entry whose contents are read from source to its end, compressing them as they are read.

The sizes and CRC-32 go in a data descriptor after the contents. Set entry.size to the expected size when it may reach 4 GiB, so the local header carries ZIP64 sizes as the format asks; the central directory is right either way.
