Writer: writing a zip archive to a file or any stream.

Source: writer.pep

Writer

struct Writer

Writes a zip archive: each add writes one entry's local header and contents, and finish() writes the central directory that lists them.

Each entry is stored or compressed with DEFLATE, as its method says; an entry from memory that DEFLATE would not make smaller is stored instead. Names are written in UTF-8, with the flag that says so when they are not ASCII, and each entry carries its modification time to the second (the Unix extended timestamp) besides the format's two-second local time. ZIP64 records are added where an entry, an offset or the entry count needs them, so archives and entries may pass 4 GiB and 65,535 entries.

Entries from a stream (add_file, add_stream) are written as they are read, with their sizes and CRC-32 in a data descriptor after the contents, so the sink need not seek and the file need not fit in memory. Nothing is written in the background: errors come back from the call that hit them, and an archive whose finish() was not reached is incomplete.

Example

import zip;

main(): int {
    var writer = zip.Writer.create("bundle.zip").value();
    writer.add_file("docs/readme.md", "readme.md").value();
    writer.add("version.txt", "1.0.0".bytes()).value();
    writer.finish().value();
    return 0;
}

Fields

comment

var comment: String

The archive's comment, written by finish().

level

var level: int

The DEFLATE level for compressed entries, from 1 (fastest) through 9 (smallest); 6 by default, as zlib's.

name

var name: String

The archive's name in messages.

add_entry

Adds an entry with the header fields of entry (name, method, modification time, mode, comment) and the contents data. The size and CRC-32 written are those of data, whatever entry holds, and a directory (a name ending with /) is written with no contents.

add_file

add_file(name: String, path: io.Path, method: Method = Method.Deflate): io.IoResult<void>

Adds the file at path as the entry name, reading it in chunks so it need not fit in memory. The entry takes the file's modification time and, on Unix, its permission bits.

Parameters

  • name — the entry's path in the archive
  • path — the file to add
  • method — how to store the contents

Returns

  • an Ok result; the error reading the file, or an error as for add

Panics

  • if finish() was called ("zip.Writer used after finish()")

add_stream

add_stream(entry: Entry, source: io.Reader): io.IoResult<void>

Adds an entry with the header fields of entry whose contents are read from source to its end, compressing them as they are read.

The sizes and CRC-32 go in a data descriptor after the contents. Set entry.size to the expected size when it may reach 4 GiB, so the local header carries ZIP64 sizes as the format asks; the central directory is right either way.

Parameters

  • entry — the entry's header fields
  • source — the stream holding the contents

Returns

  • an Ok result; the error reading source, or an error as for add

Panics

  • if finish() was called ("zip.Writer used after finish()")

finish

finish(): io.IoResult<void>

Writes the central directory and the end records, then closes the file when create opened it. Later calls do nothing.

Returns

  • an Ok result; an error when writing or closing fails
