zip

entry.pep

Entry and Method: what the central directory says about each file in an archive, and the helpers the reader and writer share.

Source: entry.pep

Method

enum Method

How an entry's contents are stored.

Cases

Stored

Stored

Stored as they are, uncompressed (method 0).

Deflate

Deflate

Compressed with DEFLATE (method 8), as nearly every zip tool writes.

Other

Other

Any other method, such as bzip2, LZMA or zstd: the entry is listed, but reading it is an error naming the method. Entry.method_code holds the number.

Entry

struct Entry

One entry of a zip archive: a file or directory, as the central directory describes it, without its contents.

Example

import zip;

var entry = zip.Entry("bin/run.sh");
entry.mode = 493;   # octal 755: rwxr-xr-x
entry.method = zip.Method.Stored;

Fields

name

var name: String

The path in the archive, with / between components; a directory's ends with /.

is_directory

var is_directory: bool

Whether the entry is a directory.

is_symlink

var is_symlink: bool

Whether the entry is a Unix symbolic link, whose contents are the path it points to. Extracting skips it.

size

var size: ulong

The length of the contents in bytes, uncompressed.

compressed_size

var compressed_size: ulong

The length of the stored contents in bytes, compressed.

crc32

var crc32: uint

The CRC-32 of the uncompressed contents.

method

var method: Method

How the contents are stored.

method_code

var method_code: uint

The method's number from the zip format: 0 stored, 8 DEFLATE, 12 bzip2, 14 LZMA, 93 zstd, and so on.

modified

var modified: os.SystemTime

The modification time. Archives record it in local time to two seconds, with no time zone, unless they also carry the Unix extended timestamp, which this package reads and writes; without it the local time is taken as UTC.

is_encrypted

var is_encrypted: bool

Whether the contents are encrypted (ZipCrypto or AES). Reading an encrypted entry is an error.

comment

var comment: String

The entry's comment; usually empty.

mode

var mode: uint

The Unix permission bits, such as 420 (octal 644, rw-r--r--); 0 when the archive was not made on Unix.

Constructor

Entry()

construct(name: String = "", method: Method = Method.Deflate)

Makes an entry with the given name and method, modified now, with mode 420 (octal 644) for a file and 493 (octal 755) for a directory (a name ending with /).

Parameters

  • name — the path in the archive
  • method — how to store the contents
