Message

struct Message

A message a WebSocket received: text, binary, or the peer's close.

A message split into fragments arrives whole. For a Close, close_code and text() say why the peer closed.

For a Close, the peer's status code (CLOSE_NO_STATUS when it gave none); 0 otherwise.

WebSocket

struct WebSocket

One WebSocket connection (RFC 6455), as a client (connect) or a server (accept), over TCP or TLS.

receive returns the next text or binary message whole, joining fragments, answering pings, and skipping pongs; when the peer closes, it answers the close and returns a Close message. send_text, send_binary and ping send; close runs the closing handshake. A frame that breaks the protocol, an invalid UTF-8 text, or a message over max_message_size closes the connection with the matching status code and makes receive return an error.

A connection belongs to one task at a time: use it from the task that opened it, or hand it over. In a task of async.run, a call that waits parks only the task.

Example

import websocket;

main(): int {
    var socket = websocket.WebSocket.connect("ws://localhost:8080/chat").value();
    socket.send_text("hello");
    var reply = socket.receive().value();
    print(reply.text());
    socket.close();
    return 0;
}

Fields

request

var request: http.Request

The opening handshake's request: on a server, the client's (its url is the target, such as /chat?room=1, and its headers hold Origin, Sec-WebSocket-Protocol and the like); on a client, the one it sent.

max_message_size

var max_message_size: ulong

The largest message receive accepts; a larger one closes the connection with CLOSE_TOO_BIG.

Opens a connection to url, a ws:// or wss:// URL, and runs the opening handshake. wss:// checks the server's certificate against the system's root certificates.

Returns

connect

static connect(url: String, connector: tls.TlsConnector): Result<WebSocket>

Opens a connection to url and runs the opening handshake, using connector for wss://, such as one that trusts a private certificate authority.

Parameters

  • url — the server's URL, such as wss://example.com/chat
  • connector — the TLS connector for wss://; unused for ws://

Returns

  • the open connection; an error when the URL is not a WebSocket URL, the connection fails, or the server refuses the upgrade

accept

static accept(tcp: io.TcpStream): Result<WebSocket>

Runs the server's side of the opening handshake on a connection a listener accepted: reads the client's upgrade request and answers it with 101 Switching Protocols.

A request that is not a valid upgrade is answered with 400 Bad Request (or 426 Upgrade Required for a version other than 13), and the connection is closed.

Parameters

  • tcp — the accepted connection

Returns

  • the open connection, whose request is the client's; an error when the request is not a valid upgrade or the connection fails

Example

var listener = io.TcpListener.bind(io.SocketAddress.parse("0.0.0.0:8080").value()).value();
var (tcp, peer) = listener.accept().value();
var socket = websocket.WebSocket.accept(tcp).value();
var message = socket.receive().value();
socket.send_text("you said " + message.text());

set_read_timeout

set_read_timeout(milliseconds: ulong): Result<void>

Makes receive and close give up with an error when nothing arrives for milliseconds, which also closes the connection. By default they wait as long as it takes, so set one when a peer might never answer.

Parameters

  • milliseconds — how long a read may wait; 0 to wait forever

Returns

  • an Ok result; the platform error when the socket refuses it

ping(data: u8[]): Result<void>

Sends a ping; the peer answers with a pong, which receive skips.

Parameters

Returns

send_frame

send_frame(frame: Frame): Result<void>

Sends one frame as it is, masked on a client. To send a message in fragments, send a Text or Binary frame with fin false, then Continuation frames, the last with fin true; control frames may go between them.

Parameters

  • frame — the frame to send

Returns

  • an Ok result once it is written; an error when the connection is closed, the frame is a Close (use close), a control frame is fragmented or carries more than MAX_CONTROL_PAYLOAD bytes, or the write fails

receive

receive(): Result<Message>

Receives the next text or binary message, or the peer's close.

Answers each ping with a pong and skips pongs on the way. When the peer closes, it answers with a close, closes the connection, and returns a Close message.

Returns

  • the message; an error when the connection is closed, ends without a close, or the peer breaks the protocol (which closes it with the matching status code)

close

close(code: int = CLOSE_NORMAL, reason: String = ""): Result<void>

Runs the closing handshake: sends a close with code and reason, reads until the peer's close (dropping any messages still on the way), and closes the connection. Closing a closed connection does nothing. It waits for the peer as receive does: see set_read_timeout.

Parameters

  • code — the status code, such as CLOSE_NORMAL
  • reason — why, in at most 123 bytes of UTF-8

Returns

  • an Ok result once the connection is closed; an error when writing the close fails or the peer ends the connection without one
