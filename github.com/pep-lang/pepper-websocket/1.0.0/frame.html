websocket

frame.pep

WebSocket frames (RFC 6455, section 5): Opcode, Frame, and the wire format with encode_frame and decode_frame.

Source: frame.pep

Opcode

enum Opcode: u8

What a frame carries (RFC 6455, section 5.2).

Cases

Continuation

Continuation = 0

A later fragment of a message that a Text or Binary frame began.

Text

Text = 1

A UTF-8 text message, or its first fragment.

Binary

Binary = 2

A binary message, or its first fragment.

Close

Close = 8

The closing handshake: an optional status code and reason.

Ping

Ping = 9

A ping, which the peer answers with a Pong carrying the same bytes.

Pong

Pong = 10

The answer to a Ping, or an unasked heartbeat.

MAX_CONTROL_PAYLOAD

const MAX_CONTROL_PAYLOAD: ulong = 125

The most bytes a control frame (Close, Ping, Pong) may carry.

Frame

struct Frame

One frame: an opcode, the payload, and whether it ends its message.

Example

var frame = websocket.Frame(websocket.Opcode.Text, "hi".bytes());
var bytes = websocket.encode_frame(frame);   # 81 02 68 69

Fields

fin

var fin: bool

Whether this is the last frame of its message (the FIN bit).

The payload, unmasked.

Methods

is_control

is_control(): bool

Returns whether this is a control frame: Close, Ping or Pong.

Returns

  • true for an opcode of 8 or more

encode_frame

encode_frame(frame: Frame): u8[]

Encodes frame unmasked, as a server sends it.

Parameters

  • frame — the frame to encode

Returns

  • the frame's bytes: header, then payload

Example

var bytes = websocket.encode_frame(websocket.Frame(websocket.Opcode.Ping, Array<u8>()));
# bytes holds 89 00

encode_frame

encode_frame(frame: Frame, mask: u8[]): u8[]

Encodes frame masked with mask, as a client sends it: each payload byte is XORed with mask[i % 4].

Parameters

  • frame — the frame to encode
  • mask — the four-byte masking key; a client picks a new random one for each frame

Returns

  • the frame's bytes: header, masking key, then masked payload

Panics

  • if mask does not hold exactly 4 bytes

decode_frame

decode_frame(bytes: u8[], max_payload: ulong): Result<(Frame, ulong)?>

Decodes the frame at the start of bytes.

Checks what RFC 6455 requires of every frame: no reserved bits (this package negotiates no extensions), a known opcode, and a control frame that is not fragmented and carries at most MAX_CONTROL_PAYLOAD bytes. Whether a frame must be masked depends on who sent it, so that is left to the caller (see Frame.masked).

Parameters

  • bytes — the received bytes, starting at a frame
  • max_payload — the largest payload to accept

Returns

  • the frame and how many bytes of bytes it took; Empty when bytes does not hold the whole frame yet; an error when the frame breaks the protocol or its payload is over max_payload

Example

var bytes = [0x81 as u8, 0x02, 0x68, 0x69];   # "hi", unmasked
var (frame, used) = websocket.decode_frame(bytes, 1024).value().value();
# frame.opcode == websocket.Opcode.Text, used == 4
