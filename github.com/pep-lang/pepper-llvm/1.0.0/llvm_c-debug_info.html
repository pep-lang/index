llvm_c/debug_info.pep

The parts of llvm-c/DebugInfo.h a compiler needs to emit DWARF and CodeView: the DIBuilder, files, compile units, functions, types, variables, scopes and locations.

Every LLVMMetadataRef and LLVMDIBuilderRef is void*; LLVMDWARFSourceLanguage, LLVMDWARFEmissionKind, LLVMDIFlags and LLVMModuleFlagBehavior are int; LLVMDWARFTypeEncoding is uint. Names are passed with their length in bytes.

Source: llvm_c/debug_info.pep

  • sdk — the SDK name, or empty
  • sdk_length — its length

  • the compile unit
