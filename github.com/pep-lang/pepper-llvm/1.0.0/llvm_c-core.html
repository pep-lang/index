llvm

llvm_c/core.pep

The parts of llvm-c/Core.h, Analysis.h and BitWriter.h that a compiler needs: contexts, modules, types, values, constants, basic blocks, the instruction builder, verification and bitcode output.

Each declaration is the C function of the same name, with C's types: every LLVM*Ref handle is void*, LLVMBool and the enums are int, unsigned is uint, and size_t and uint64_t are ulong. See the LLVM-C headers for what each does. Strings LLVM returns as char* are freed with LLVMDisposeMessage; a returned const char* is not.

Source: llvm_c/core.pep
