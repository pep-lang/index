Context

struct Context

An LLVM context (LLVMContextRef), which owns the types and constants of the modules built in it. It is disposed when the last reference to it goes away; a Module or Builder made from it holds a reference, so it outlives them.

A context is not thread-safe: use each one, and everything made in it, from one thread.

Example

var context = llvm.Context();
var i32 = context.int32_type();
var answer = i32.const_int(42);   # i32 42
