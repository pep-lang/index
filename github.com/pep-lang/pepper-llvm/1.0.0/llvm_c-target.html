llvm_c/target.pep

The parts of llvm-c/Target.h, TargetMachine.h, Error.h and Transforms/PassBuilder.h that a compiler needs: registering the host's backend, target machines, object emission, data layouts and the optimization pipeline.

LLVM's LLVMInitializeNativeTarget and LLVMInitializeAll* are inline functions in its headers, so they cannot be bound. The host's backend is declared here; every other backend's LLVMInitialize<Name>* functions exist only when LLVM was built with that backend, so llvm looks them up at run time instead (llvm.initialize_target).

Source: llvm_c/target.pep
