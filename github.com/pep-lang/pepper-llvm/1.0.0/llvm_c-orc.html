llvm

llvm_c/orc.pep

The parts of llvm-c/Orc.h and LLJIT.h needed to compile modules in memory and call them: ORC's LLJIT, thread-safe contexts and modules, and resolving the process's own symbols.

Every LLVMOrc*Ref is void*; errors are LLVMErrorRef (void*, null for success), read with LLVMGetErrorMessage.

Source: llvm_c/orc.pep
