Module: a unit of LLVM IR (functions and globals) that is verified, optimized and compiled to an object file.

Source: ir_module.pep

Module

struct Module

An LLVM module (LLVMModuleRef): the functions and global variables of one compilation unit. It is disposed when the last reference to it goes away, before the Context it holds.

Example

var context = llvm.Context();
var module = llvm.Module(context, "main");
var i32 = context.int32_type();
var answer = module.add_function("answer", llvm.Type.function(i32, Array<llvm.Type>()));

link

link(source: Module): Result<void>

Links source, a module of the same context, into this one, which then holds what source defined. source is used up: it no longer owns a module (is_owned is false). Linking moves source's contents, where linking a clone() would copy them first.

Parameters

Returns

  • Ok, or an Err when the two do not link (a symbol both define)
