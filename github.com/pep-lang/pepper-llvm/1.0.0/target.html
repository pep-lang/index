Targets: registering the host's backend, TargetMachine, and compiling a module to an object file.

Source: target.pep

initialize_native_target

[Target(Arch(x64))] initialize_native_target()

Registers the backend for the host's architecture (x86-64 or AArch64). TargetMachine.create registers every backend itself, so call this only to use llvm_c target functions directly. Calling it again does nothing.

known_backends

known_backends(): String[]

Returns the names of the backends LLVM 20 can be built with, as initialize_target takes them. A given LLVM build has some of them; the official builds and Linux distributions' have all but the experimental ones.

Returns

  • the backend names

initialize_target

initialize_target(name: String): Result<void>

Registers one backend, so target machines for its triples can be made: ARM covers armv7-* and thumbv7em-*, RISCV covers riscv32-* and riscv64-*, WebAssembly covers wasm32-*, and so on. Calling it again does nothing.

Parameters

  • name — the backend's name, as known_backends() lists it

Returns

  • Ok, or an Err when the LLVM library was built without that backend

Example

llvm.initialize_target("RISCV").value();
var machine = llvm.TargetMachine.create("riscv64-unknown-linux-gnu").value();

TargetMachine

struct TargetMachine

A target machine (LLVMTargetMachineRef): a target, CPU and options that modules are compiled for. It is disposed when the last reference to it goes away.

Example

var machine = llvm.TargetMachine.host().value();
machine.configure(module);
module.run_passes("default<O2>", machine).value();
machine.emit_to_file(module, "main.o").value();

Static methods

host

static host( level: OptLevel = OptLevel.O2, reloc: RelocMode = RelocMode.Pic, code_model: CodeModel = CodeModel.Default ): Result<TargetMachine>

Creates a target machine for the host: its triple, CPU and CPU features.

Parameters

  • level — how hard code generation optimizes
  • reloc — how code addresses itself; position-independent by default, as for PIE executables
  • code_model — which addresses code may reach directly

Returns

  • the machine, or an Err when LLVM has no backend for the host

create

static create( triple: String, cpu: String = "", features: String = "", level: OptLevel = OptLevel.O2, reloc: RelocMode = RelocMode.Pic, code_model: CodeModel = CodeModel.Default ): Result<TargetMachine>

Creates a target machine for any triple a backend of the LLVM library handles, such as aarch64-apple-darwin, riscv64-unknown-linux-gnu, wasm32-unknown-unknown or x86_64-pc-windows-msvc. Registers every backend first (initialize_all_targets).

Parameters

  • triple — the target triple, such as aarch64-apple-darwin
  • cpu — the CPU name; empty for the target's generic CPU
  • features — the CPU features (+avx2,-sse4a); empty for the CPU's own
  • level — how hard code generation optimizes
  • reloc — how code addresses itself
  • code_model — which addresses code may reach directly

Returns

  • the machine, or an Err when no registered backend handles triple
