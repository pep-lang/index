DebugBuilder: debug info (DWARF, or CodeView on Windows) for a module, so debuggers can map machine code back to source lines, functions, types and variables.

Source: debug_info.pep

DebugBuilder

struct DebugBuilder

Makes the debug info of one module (LLVMDIBuilderRef). Make one per module, describe the compile unit, then each function, type and variable, attach locations to instructions, and call finalize() before verifying or emitting the module.

It adds the Debug Info Version module flag, which LLVM needs to keep the debug info; set_dwarf_version and use_codeview add the others a platform's debugger expects.

Example

var debug = llvm.DebugBuilder(module);
var file = debug.file("main.pep", "/src");
var unit = debug.compile_unit(file, "pepper 0.2");
var int_type = debug.basic_type("int", 32, llvm.DwarfEncoding.Signed);
var signature = debug.subroutine_type(file, int_type, [int_type]);
var info = debug.function(unit, "twice", file, 3, signature);
function.set_subprogram(info);
builder.set_location(debug.location(4, 12, info));
# ... build the body ...
debug.finalize();

Methods

set_dwarf_version

set_dwarf_version(version: uint)

Sets the DWARF version to emit (the Dwarf Version module flag), as Linux and macOS debuggers expect; 5 is current, 4 the most widely read.

Parameters

  • version — the DWARF version

use_codeview

use_codeview()

Emits CodeView, which Windows debuggers read, instead of DWARF (the CodeView module flag).

finalize

finalize()

Resolves the debug info made so far. Call it once, after the last function is described and before the module is verified or emitted.

function

function( scope: Metadata, name: String, file: Metadata, line: uint, subroutine_type: Metadata, linkage_name: String = "", local: bool = false, scope_line: uint = 0, optimized: bool = false ): Metadata

Describes a function definition. Attach the result to the function with Value.set_subprogram; it is also the scope of the locations and variables inside the function.

Parameters

  • scope — the enclosing scope: the compile unit, or a file
  • name — the function's source name
  • file — the file it is in
  • line — the line it is declared on
  • subroutine_type — its type, from subroutine_type
  • linkage_name — its symbol name, when it differs from name
  • local — whether it is private to the compile unit
  • scope_line — the line its body starts on; 0 for line
  • optimized — whether it is optimized

Returns

  • the function's debug info
