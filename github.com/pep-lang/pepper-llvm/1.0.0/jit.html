jit.pep

Jit: compiles modules in memory and returns the addresses of their functions, to call from the running program.

Source: jit.pep

Jit

struct Jit

An ORC JIT (LLVMOrcLLJITRef) for the host. Add modules made in a thread-safe context (Context(thread_safe = true)), then lookup a function and cast its address to a C function pointer type to call it. Code it compiles can call the running program's C functions (puts, malloc, ...). It is disposed, with the code it compiled, when the last reference to it goes away.

Example

var jit = llvm.Jit.create().value();
var context = llvm.Context(thread_safe = true);
var module = llvm.Module(context, "jitted");
# ... build `add(i32, i32): i32` ...
jit.add_module(module).value();
var add = jit.lookup("add").value() as extern (int, int) => int;
var five = add(2, 3);

add_module

add_module(module: Module): Result<void>

Adds a module, which the JIT compiles when one of its symbols is looked up. The JIT takes the module over: afterwards module is empty (is_owned() is false) and must not be used.

Parameters

  • module — a module made in a thread-safe context

Returns

  • Ok, or an Err when the module's context is not thread-safe or a symbol is defined twice

Panics

  • if module was already given to a JIT

lookup

lookup(name: String): Result<__ptr<void>>

Compiles what a symbol needs, and returns its address. Cast it to the C function pointer type matching the function's signature (as extern (int) => int) to call it.

Parameters

  • name — the function's or global's name

Returns

  • the address, or an Err when no added module or the program defines name
