tui

text_input.pep

TextInput: an editable field of text, on one row or wrapped over many, with a cursor, a selection and pastes; TextInputState holds the text and the cursor from frame to frame.

Source: text_input.pep

TextInputState

struct TextInputState

The state of a TextInput: the text, the cursor, the selection and the scroll. Feed it the app's events with handle_event; drawing scrolls it to keep the cursor in view.

The cursor and the selection move a character at a time: a code point with the combining marks after it. Widths are display widths, so a wide character takes two columns.

Example

import tui;

var state = tui.TextInputState();
state.set_text("hello");
state.paste("\nworld");   # one row: the line end becomes a space
assert(state.text == "hello world", "pasted at the cursor");

Fields

multiline

var multiline: bool

Whether the field takes line ends, from Enter and pastes, and wraps its text over the rows of its area; otherwise it is one row that scrolls sideways.

keep_newlines

var keep_newlines: bool

For a one-row field, whether a paste keeps its line ends, each shown as "⏎", rather than turning each into a space.

paste_truncated

var paste_truncated: bool

Whether the last paste was cut short: pepper-term keeps only the start of a paste past its limit (a megabyte).

scroll

var scroll: int

The first column (one row) or the first row (multiline) shown.

insert

insert(value: String)

Puts value in at the cursor, in place of the selection, and moves the cursor past it. Line ends go in as they are, even in a one-row field (which shows each as "⏎"); paste turns them into spaces there.

Parameters

  • value — the text to put in

paste

paste(value: String, truncated: bool = false)

Puts a paste in at the cursor, as Event.Paste gives it: in a one-row field without keep_newlines, each line end becomes a space. Sets paste_truncated to truncated.

Parameters

  • value — the pasted text, with "\n" line ends
  • truncated — whether the paste was cut short

handle_event

handle_event(event: Event): bool

Acts on an event: a key (see handle_key) or a paste.

Parameters

  • event — the event, as Events.next gives it

Returns

  • true when it acted on the event; the app handles the rest

handle_key

handle_key(key: term.KeyEvent): bool

Acts on a key as a text field does: a character goes in at the cursor; Backspace and Delete remove the selection or the character before or after the cursor; Left, Right, Home and End move the cursor (to the start or end of its line), selecting with Shift held; in a multiline field Enter puts in a line end, and Up and Down move a row as the last draw wrapped it.

Keys with Ctrl or Alt, Tab, Escape, and Enter in a one-row field are left to the app.

Parameters

  • key — the key, as Event.Key gives it

Returns

  • true when it acted on the key

TextInput

struct TextInput

An editable field of text, drawn from a TextInputState: the text, the selection in selection_style, and the cursor as a cell in cursor_style. A one-row field scrolls sideways to keep the cursor in view; a multiline one wraps at the area's width, keeps its line ends, and scrolls down.

Text that could move the cursor or send the terminal a sequence shows harmlessly: a line end in a one-row field as "⏎", and any other control character (C0, DEL and C1) as U+FFFD.

Example

import tui;
import [Block, TextInput, TextInputState] from tui;

var input = TextInput(block = Block(title = "Name"));
var state = TextInputState();
# in the event loop: state.handle_event(event.value());
# in a frame: frame.render_stateful_widget(input, area, state);
