The screen as data​: a Buffer of Cells, which widgets draw into and which Terminal compares with the last frame's to write only what changed.

Source: buffer.pep

Cell

[Value] struct Cell

One character cell: the text it shows and its style.

A wide character's cell is followed by a cell whose symbol is "", which the wide character covers.

Buffer

struct Buffer

A rectangle of cells, row by row. Writes outside its area are dropped, so widgets clip without checking.

Example

import tui;

var buffer = tui.Buffer(tui.Rect(0, 0, 5, 1));
buffer.set_string(1, 0, "hi", tui.Style());
assert(buffer.to_lines()[0] == " hi  ", "drawn at column 1");

set_string

set_string(x: int, y: int, value: String, style: Style, max_width: int = 1000000): int

Writes value from x along row y, a character a cell (two for a wide one), laying style over each cell's, and stops before max_width columns or the edge. Control characters are skipped, and zero-width characters join the cell before them.

Parameters

  • x — the first column
  • y — the row
  • value — the text
  • style — the style to lay over the cells
  • max_width — the most columns to take

Returns

  • the column after the last one written

set_line

set_line(x: int, y: int, line: Line, max_width: int): int

Writes line from x along row y, each span in the line's style with its own laid over it, and stops before max_width columns.

Parameters

  • x — the first column
  • y — the row
  • line — the line
  • max_width — the most columns to take

Returns

  • the column after the last one written

diff

diff(previous: Buffer): CellUpdate[]

Returns the cells that differ from previous, which covers the same area, as the updates to bring a screen showing previous to this buffer: each cell's column, row and the cell. A wide character's covered cell is never an update, and the cells a wide character covered in previous are.

Parameters

  • previous — the buffer the screen shows now

Returns

  • the updates, row by row

to_lines

to_lines(): String[]

Returns each row's symbols joined, top to bottom, for checking what a buffer shows in a test. A wide character's covered cell adds nothing.

Returns

  • the rows

assert_lines

assert_lines(expected: String[])

Panics unless the buffer shows expected, a string per row, as to_lines() gives them: a snapshot check for tests, which prints both screens when they differ.

Parameters

  • expected — the rows, top to bottom

Panics

  • if the rows differ, at the line of the call

Example

import tui;

var buffer = tui.Buffer(tui.Rect(0, 0, 3, 1));
buffer.set_string(0, 0, "ok", tui.Style());
buffer.assert_lines(["ok "]);
