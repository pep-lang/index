Tabs

struct Tabs

A row of titles, padded and separated by divider, with the selected one highlighted.

Example

import tui;
import [Tabs] from tui;

var tabs = Tabs(["Files", "Search", "Help"], selected = 1);
# " Files │ Search │ Help "

Fields

titles

var titles: Line[]

The titles, left to right.

selected

var selected: ulong

The selected title.

block

var block: Block

The block around the tabs; borderless by default.

style

var style: Style

The style of the whole area.

highlight_style

var highlight_style: Style

The style laid over the selected title.

divider

var divider: String

Drawn between titles.

padding_left

var padding_left: String

Drawn before each title.

padding_right

var padding_right: String

Drawn after each title.

Constructor

Tabs()

construct( titles: Line[], selected: ulong = 0, block: Block = Block(borders = BORDER_NONE), style: Style = Style(), highlight_style: Style = Style(reverse = true), divider: String = "│", padding_left: String = " ", padding_right: String = " " )

Makes tabs.

Parameters

  • titles — the titles, left to right
  • selected — the selected title
  • block — the block around the tabs
  • style — the style of the whole area
  • highlight_style — the style of the selected title
  • divider — drawn between titles
  • padding_left — drawn before each title
  • padding_right — drawn after each title

Methods

handle_mouse

handle_mouse(event: term.MouseEvent, area: Rect): bool

Selects the title a left click landed on, its padding included, with the tabs drawn in area. Keep the Tabs from frame to frame, or its selected in the app, to keep the choice.

Parameters

  • event — the mouse event, as Event.Mouse gives it
  • area — where the tabs are drawn, such as Terminal.area_of gives

Returns

  • true when the click selected a title
