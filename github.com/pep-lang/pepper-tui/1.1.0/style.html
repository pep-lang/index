tui

style.pep

Styles that layer: a Style sets only some of a cell's colors and modifiers, and patch lays one style over another, so a widget's style, a line's and a span's combine as Ratatui's do. Colors are pepper-term's Color: the 16 basic colors, the 256 indexed ones, and RGB.

Source: style.pep

BOLD

const BOLD = 1

The bold modifier, for Style.add_modifiers and Style.remove_modifiers.

DIM

const DIM = 2

The dim (faint) modifier.

const ITALIC = 4

The italic modifier.

UNDERLINE

const UNDERLINE = 8

The underline modifier.

REVERSE

const REVERSE = 16

The reversed modifier: foreground and background swapped.

Style

[Value] struct Style

Some of a cell's colors and modifiers. What a style leaves unset comes from the style beneath it when patch lays it over another.

Example

import tui;
import term;
import [BasicColor, Color] from term;

var base = tui.Style(foreground = Color.Basic(BasicColor.White), bold = true);
var warning = tui.Style(foreground = Color.Basic(BasicColor.Yellow));
var both = base.patch(warning);   # yellow and bold

Constructor

Style()

construct( foreground: Color = Color.Default, background: Color = Color.Default, bold: bool = false, dim: bool = false, italic: bool = false, underline: bool = false, reverse: bool = false )

Makes a style. A color left as Color.Default is not set, so it comes from the style beneath; use fg or bg to set the terminal's own color over another.

Parameters

  • foreground — the text color
  • background — the background color
  • bold — whether to turn bold on
  • dim — whether to turn dim on
  • italic — whether to turn italic on
  • underline — whether to turn underline on
  • reverse — whether to turn reversed on
