list.pep

List: items one under another, one of them selected, scrolled to keep the selection in view; ListState holds the selection and the scroll.

Source: list.pep

ListState

struct ListState

The state of a List or a Table from frame to frame: which item is selected and how far it is scrolled. Drawing moves offset so the selected item shows, and keeps selected below the item count.

Example

import tui;

var state = tui.ListState();
state.select_next();   # selects item 0
state.select_next();   # item 1

select_next

select_next()

Selects the next item, or the first when none is; drawing keeps it at the last item.

select_previous

select_previous()

Selects the item before, staying at the first; the first when none is selected.

The state of a Table: the selected row and the scroll.

List

struct List

Items one under another, each a Text (one or more rows), with the selected one highlighted and marked with highlight_symbol.

As a StatefulWidget<ListState> it draws the selection and scrolls to it; as a Widget it draws the items from the top with none selected.

Example

import tui;
import [Block, List, ListState, Style] from tui;

var list = List(["one", "two", "three"], block = Block(title = "Items"), highlight_symbol = "> ");
var state = ListState();
state.select_next();
# in a frame: frame.render_stateful_widget(list, area, state);

Fields
