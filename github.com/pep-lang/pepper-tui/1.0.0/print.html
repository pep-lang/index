tui 1.0.0

Full-screen terminal apps in the style of Ratatui: widgets, layout and diffed rendering over pepper-term

tui

Full-screen terminal apps in the style of Ratatui: immediate-mode drawing, layout by constraints, styled text, and widgets, over pepper-term.

Bring it in with import tui.

  • init, restore, Terminal, Frame: draw a frame at a time; only the cells that changed are written
  • Backend, TermBackend, TestBackend: where frames go
  • Buffer, Cell, CellUpdate, Rect: the screen as data
  • Layout, Constraint, Direction: split an area
  • Style, BOLD and the other modifiers, Span, Line, Text, Alignment, char_width, display_width: styled text
  • Widget, StatefulWidget, and the widgets Block, Paragraph, List, Table, Tabs, Gauge, Sparkline, BarChart and Scrollbar
  • Events, Event: keys and resizes

Example

import tui;
import [Event, Paragraph] from tui;

main(): int {
    var terminal = tui.init();
    var events = tui.Events();
    while (true) {
        terminal.draw((frame) => {
            frame.render_widget(Paragraph("Hello! Press q to quit."), frame.area);
        });
        var event = events.next();
        if (event.is_empty()) {
            break;
        }
        if (event.value() is Key(key)) {
            if (key.text == "q") {
                break;
            }
        }
    }
    tui.restore();
    return 0;
}

Layout

struct Layout

Splits a rectangle into parts along one direction, one per constraint.

The solver is deterministic and never fails: each part first gets what its constraint asks for (a Fill nothing, a Min or a Max its size). Space left over goes to the Fill parts by weight or, with none, shared evenly by the Min parts, and stays empty at the end otherwise. When the parts ask for more than there is, every part shrinks in proportion to what it asked for, so all of them still fit. Rounding leftovers go to the first parts.

Example

import tui;
import [Constraint, Direction] from tui;

var parts = tui.Layout(Direction.Vertical, [Constraint.Length(1), Constraint.Fill(1)]).split(tui.Rect(0, 0, 10, 5));
# parts[0] is Rect(0, 0, 10, 1); parts[1] is Rect(0, 1, 10, 4)

init

init(): Terminal

Sets up the terminal for a full-screen app and returns a Terminal that draws on it: raw mode on, the alternate screen, colors on, the cursor hidden, the screen blank.

Call restore when the app ends. The terminal is also restored when the program ends without it: at the end of main, on a panic, and on SIGTERM, SIGHUP, SIGINT or SIGQUIT (POSIX). process.exit runs no exit handlers, so call restore before it.

Call it before anything else turns pepper-term's raw mode on (a term.RawMode, a term.LineReader reading a line): its signal handlers would then stay in place of these, and a panic would leave the alternate screen up. To set the terminal up again after restore, let the old Terminal go first: its backend's raw mode, freed later, would turn the new one's off.

Returns

  • the terminal

Example

import tui;

main(): int {
    var terminal = tui.init();
    # ... draw frames and read events ...
    tui.restore();
    return 0;
}

restore

restore()

Puts the terminal back as init found it: the main screen, the cursor showing, and raw mode off. Does nothing when it is already restored.
