Block

struct Block

A border with a title, drawn around an area; other widgets take one to draw themselves inside it.

Example

import tui;
import [Block, BorderType] from tui;

var block = Block(title = "Files", border_type = BorderType.Rounded);
# ╭Files───╮
# │        │
# ╰────────╯

Fields

title

Which borders to draw: BORDER_TOP, BORDER_RIGHT, BORDER_BOTTOM and BORDER_LEFT or-ed together, or BORDER_ALL.

border_type

The lines the borders are drawn with.

The style of the borders, laid over style.

style

The style of the whole area, borders and inside.

padding

var padding: int
