Table

struct Table

Rows of cells in columns, with an optional header row and the selected row highlighted. widths sizes the columns as a horizontal Layout does, with column_spacing between them.

As a StatefulWidget<TableState> it draws the selection and scrolls to it; as a Widget it draws the rows from the top with none selected.

Example

import tui;
import [Constraint, Row, Table, TableState] from tui;

var table = Table(
    [Row(["Ada", "1815"]), Row(["Grace", "1906"])],
    [Constraint.Length(6), Constraint.Length(4)],
    header = Row(["Name", "Born"])
);
