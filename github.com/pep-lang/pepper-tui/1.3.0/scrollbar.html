ScrollbarState

struct ScrollbarState

How long the content a Scrollbar scrolls is, and where the view is.

Example

import tui;

var state = tui.ScrollbarState(100);   # 100 rows of content
state.position = 40;                   # scrolled to row 40

Fields

content_length

var content_length: int

How long the content is, such as its number of rows; 0 draws no scrollbar.

position

var position: int

The scroll position, such as the first row in view: from 0 to content_length less the rows in view.

viewport_content_length

var viewport_content_length: int

How much of the content shows at once; 0 for the track's length.

Constructor

Makes a state.

Parameters

  • content_length — the number of positions
  • position — the current position
  • viewport_content_length — how many positions show at once

Methods

handle_mouse

handle_mouse(event: term.MouseEvent, area: Rect): bool

Acts on a mouse event: the wheel over area scrolls by one, a left click on the track of the Scrollbar last drawn with this state moves the thumb there, and dragging the thumb moves it along. The position stays from 0 to content_length less the viewport.

The state can scroll content with no scrollbar drawn, such as a Paragraph drawn with scroll = state.position; set viewport_content_length to the rows it shows.

Parameters

  • event — the mouse event, as Event.Mouse gives it
  • area — where the wheel scrolls, such as the scrolled widget's area from Terminal.area_of

Returns

  • true when it acted on the event

Scrollbar

struct Scrollbar

A scrollbar: arrows at the ends, a track between them, and a thumb as long as the share of the content in view, placed by the position.

Example

import tui;
import [Scrollbar, ScrollbarOrientation, ScrollbarState] from tui;

var bar = Scrollbar(ScrollbarOrientation.VerticalRight);
# in a frame: frame.render_stateful_widget(bar, area, ScrollbarState(100, 40));

Makes a scrollbar. Empty symbols take the defaults: "║", "▲" and "▼" for a vertical one, "═", "◄" and "►" for a horizontal one, and "█" for the thumb.
