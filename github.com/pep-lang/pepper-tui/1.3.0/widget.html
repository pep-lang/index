The widget traits: a Widget draws itself into a buffer, and a StatefulWidget draws with state the app keeps between frames, such as a list's selection.

Source: widget.pep

Widget

trait Widget

Something that draws itself into an area of a buffer. Every widget of this package is one, and an app writes its own the same way.

Example

import tui;
import [Buffer, Rect, Style, Widget] from tui;

struct Hello {}

extend Hello with Widget {
    render(area: Rect, buffer: Buffer) {
        buffer.set_string(area.x, area.y, "hello", Style(), area.width);
    }
}

Methods

render

render(area: Rect, buffer: Buffer)

Draws the widget into area of buffer.

Parameters

  • area — where to draw; the widget draws nothing outside it
  • buffer — the buffer to draw into

StatefulWidget

trait StatefulWidget<TState>

A widget that draws with state the app keeps from frame to frame: the widget reads it, and may change it (a list scrolls its offset to keep the selection in view).

Type parameters

  • TState — the state's type, such as ListState

Methods

render

render(area: Rect, buffer: Buffer, state: TState)

Draws the widget into area of buffer with state.

Parameters

  • area — where to draw
  • buffer — the buffer to draw into
  • state — the state, which the widget may change
