Rectangles of cells: Rect, the area a widget draws in.

Source: geometry.pep

Rect

[Value] struct Rect

A rectangle of cells: its top-left corner, counted from 0 at the top left of the screen, and its size. A size below zero counts as zero.

Example

import tui;

var area = tui.Rect(0, 0, 20, 5);
var inside = area.inner(1, 1);   # Rect(1, 1, 18, 3)
