Gauge: a bar filled to a ratio, with a label.

Source: gauge.pep

Gauge

struct Gauge

A bar filled from the left to ratio of its width, with a label (the percentage by default) in the middle row. The label shows reversed where the bar is filled, so it stays readable.

Example

import tui;
import [Gauge, Style] from tui;

var progress = Gauge(0.42);   # filled to 42%, labeled "42%"

Fields

ratio

var ratio: double

How full the bar is, from 0 to 1; values outside are clamped.

label

var label: String

The label; "" for the percentage.

block

var block: Block

The block around the gauge; borderless by default.

style

var style: Style

The style of the whole area.

gauge_style

var gauge_style: Style

The style of the filled part.

use_unicode

var use_unicode: bool

Whether to fill the last cell by eighths, with Unicode's partial blocks, rather than by whole cells.

Constructor

Gauge()

construct( ratio: double, label: String = "", block: Block = Block(borders = BORDER_NONE), style: Style = Style(), gauge_style: Style = Style(), use_unicode: bool = false )

Makes a gauge.

Parameters

  • ratio — how full it is, from 0 to 1
  • label — the label; "" for the percentage
  • block — the block around the gauge
  • style — the style of the whole area
  • gauge_style — the style of the filled part
  • use_unicode — whether to fill by eighths of a cell
