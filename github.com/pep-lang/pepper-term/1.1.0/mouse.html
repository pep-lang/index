term

mouse.pep

Mouse input: MouseEvent, MouseKind and MouseButton, and turning the terminal's reports (xterm's, and the Windows console's records) into them. InputDecoder (in keys) decodes reports beside key presses, and MouseMode (in terminal) turns them on. Decoding is pure, so it needs no terminal.

Source: mouse.pep

MouseKind

enum MouseKind

What a MouseEvent reports.

Cases

Down

Down

A button was pressed.

Up

Up

A button was released. Old (X10-encoded) reports do not say which, so button may be MouseButton.None.

Drag

Drag

The mouse moved with a button held (MouseTracking.Drag and MouseTracking.Motion).

Moved

Moved

The mouse moved with no button held (MouseTracking.Motion only).

ScrollUp

ScrollUp

The wheel turned away from the user.

ScrollDown

ScrollDown

The wheel turned toward the user.

ScrollLeft

ScrollLeft

The wheel tilted left.

ScrollRight

ScrollRight

The wheel tilted right.

MouseButton

enum MouseButton

Which button a MouseEvent is about.

Cases

Left

Left

The left (primary) button.

Middle

Middle

The middle button, or pressing the wheel.

Right

Right

The right button.

None

None

No button: moves, the wheel, and releases that do not say which.

MouseEvent

struct MouseEvent

One mouse report: what happened, the button, the cell it happened in, and the modifiers held.

Many terminals keep Shift for themselves (to select text while the program has the mouse), so shift is rarely seen, and some keep Alt or Ctrl as well.

Fields

kind

const kind: MouseKind

What happened.

button

const button: MouseButton

The button pressed, released or held; MouseButton.None for moves and the wheel.

column

const column: ulong

The column, from 0 at the left.

row

const row: ulong

The row, from 0 at the top.

ctrl

const ctrl: bool

Whether Ctrl was held.

alt

const alt: bool

Whether Alt (Meta, Option) was held.

shift

const shift: bool

Whether Shift was held.

construct( kind: MouseKind, button: MouseButton = MouseButton.None, column: ulong = 0, row: ulong = 0, ctrl: bool = false, alt: bool = false, shift: bool = false )
