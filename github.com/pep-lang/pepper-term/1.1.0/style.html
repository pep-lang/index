Color

[Value] enum Color

A text or background color, in one of the three palettes terminals offer.

Cases

Default

Default

The terminal's own color, which Style leaves alone.

Basic

Basic(color: BasicColor)

One of the 16 basic colors, which every color terminal shows.

Indexed

Indexed(index: u8)

One of the 256 colors of xterm's palette: 0 to 15 the basic ones, 16 to 231 a 6x6x6 color cube, 232 to 255 a gray ramp.

Rgb

Rgb(red: u8, green: u8, blue: u8)

A true (24-bit) color; most terminals show it, and others approximate it or ignore it.

Style

struct Style

How text looks: its colors and attributes. sequence gives the escape sequence that sets it, and paint wraps text in it.

Example

import term;
import [BasicColor, Color, Style] from term;

var warning = Style(foreground = Color.Basic(BasicColor.Yellow), bold = true);
print(warning.paint("careful", true));   # "\x1B[1;33mcareful\x1B[0m"

Methods

sequence

sequence(): String

Returns the escape sequence (SGR) that sets this style, or "" for a style that sets nothing. It changes only what the style sets, so follow the text with RESET.

Returns

  • the sequence

paint

paint(text: String, enabled: bool): String

Returns text in this style: the style's sequence, the text, then RESET. With enabled false, or a style that sets nothing, it is text alone, so output to a file or a pipe stays plain.

Parameters

  • text — the text to style
  • enabled — whether to style it; pass colors_enabled() to follow the terminal and NO_COLOR

Returns

  • the styled text

The sequence that erases the whole screen. The cursor stays where it is; follow it with move_to(0, 0) to start at the top.

move_to

move_to(row: ulong, column: ulong): String

Returns the sequence that moves the cursor to row and column, counted from 0 at the top left.

Parameters

  • row — the row, from 0
  • column — the column, from 0

Returns

Example

import term;

assert(term.move_to(0, 4) == "\x1B[1;5H", "the terminal counts from 1");
