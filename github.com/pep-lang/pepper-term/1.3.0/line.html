term

line.pep

Line editing: History, and LineEditor, which applies key events to a line of text and renders it, readline style. Editing is pure: key events in, the edited line and the bytes that draw it out, so it needs no terminal. LineReader (in terminal) runs it against the real one.

Source: line.pep

LineEditor

struct LineEditor

A line being edited: the text, the cursor, and the history that Up and Down move through. handle applies one key; render gives the bytes that redraw the line.

The keys are readline's (Emacs mode):

  • characters insert at the cursor
  • Left, Right, Ctrl+B, Ctrl+F move one character; Ctrl or Alt with Left and Right, and Alt+B and Alt+F, move one word
  • Home, End, Ctrl+A, Ctrl+E go to the start and the end
  • Backspace and Ctrl+H delete before the cursor, Delete and Ctrl+D at it (Ctrl+D on an empty line ends input)
  • Ctrl+W and Alt+Backspace delete the word before the cursor, Ctrl+U everything before it, Ctrl+K everything from it
  • Up, Down, Ctrl+P, Ctrl+N recall older and newer history entries
  • Enter submits the line, Ctrl+C abandons it

Example

import term;

var editor = term.LineEditor();
for (var key in term.KeyDecoder().feed("helo\x1B[Dl\r".bytes())) {
    editor.handle(key);
}
assert(editor.text == "hello", "Left, then insert");
assert(editor.history.entries[0] == "hello", "Enter records it");

paste

paste(text: String)

Inserts text at the cursor, as Event.Paste gives it: line ends and all, without submitting the line, and without touching the history.

Parameters

render

render(prompt: String, width: ulong = 0): String

Returns the bytes that redraw the line on the terminal row the cursor is on: a carriage return, prompt, the text, an erase to the end of the row, and the move back to the cursor.

A line wider than width columns scrolls sideways to keep the cursor in view. Each code point counts as one column. A line end (from a paste) shows as "⏎", and another control character as "\u{FFFD}", so pasted text cannot move the cursor or send the terminal sequences.

Parameters

  • prompt — the text shown before the line
  • width — the terminal's width in columns; 0 when unknown, which never scrolls

Returns

  • the text to write
