term

terminal.pep

The terminal itself: whether the standard streams are one, its size, raw mode, and reading keys and edited lines from it. Each part degrades when there is no terminal (input from a pipe or a file, output to one): raw mode does nothing, keys are decoded from the bytes as they come, lines are read plainly, and colors_enabled is false.

Source: terminal.pep

colors_enabled

colors_enabled(): bool

Returns whether to write colors and styles to standard output: it is a terminal, the NO_COLOR environment variable is unset or empty (see no-color.org), and TERM is not dumb. On Windows it also turns on the console's reading of escape sequences, and is false when the console cannot.

Returns

  • true when colors will show

Example

import term;
import [BasicColor, Color, Style] from term;

var error = Style(foreground = Color.Basic(BasicColor.Red));
print(error.paint("failed", term.colors_enabled()));

RawMode

struct RawMode

Raw mode: the terminal hands over each key as it is pressed, without echoing it, editing the line, or turning Ctrl+C into a signal, as an editor or a game needs. Making a RawMode turns it on; exit, or the last reference going away, turns it off again.

Use it in a with block, which turns raw mode off however the block ends. The terminal is also restored when the program ends while raw mode is on: at the end of main, on a panic, and on SIGTERM, SIGHUP, SIGINT or SIGQUIT (POSIX). process.exit ends the program without running exit handlers, so call restore() before it.

In raw mode on Linux and macOS, output is raw too: "\n" moves down without returning to the first column, so write "\r\n".

Without a terminal on standard input, raw mode does nothing and active is false. Raw mode is one setting of the whole terminal, so while one RawMode has it on, another is not active either.

Example

import term;

main(): int {
    with (var raw = term.RawMode()) {
        var keys = term.KeyReader();
        print(raw.active ? "press a key\r" : "not a terminal");
        var key = keys.read();
        if (!key.is_empty()) {
            print($"you pressed {key.value()}\r");
        }
    }
    return 0;
}

KeyReader

struct KeyReader

Reads key presses from standard input, decoding them with a KeyDecoder.

On a terminal in raw mode, each key arrives as it is pressed. Outside raw mode the terminal sends nothing until Enter. Without a terminal, the input's bytes are decoded as they come: text gives Key.Char events, and line ends give Key.Enter.

LineReader

struct LineReader

Reads lines from standard input for a REPL or a prompt, with editing and history (see LineEditor for the keys) when standard input and output are a terminal, and plainly otherwise.

Example

import term;
import [LineInput] from term;

main(): int {
    var reader = term.LineReader();
    while (true) {
        match (reader.read_line("> ")) {
            Line(text) => {
                print($"you typed {text}");
            }
            Interrupted => {}
            EndOfInput => {
                return 0;
            }
        }
    }
}

read_line

read_line(prompt: String): LineInput

Writes prompt, then reads one line.

On a terminal, the line is edited in raw mode, which is on only while this runs, and added to the history when Enter submits it. Without one, prompt is written and a line is read up to "\n" (a "\r" before it is dropped); the last line need not end with one.

Parameters

  • prompt — the text to show before the line

Returns

  • the line, Interrupted after Ctrl+C, or EndOfInput at the end of input
