term

term

Interactive terminal programs: raw mode, key and mouse input, bracketed paste, line editing with history, cursor control, and 16, 256 and true colors, on Linux, macOS (termios) and Windows (the Console API).

Bring it in with import term. Decoding input (InputDecoder) and editing lines (LineEditor) are pure, bytes in and events or text out, so they work and test without a terminal. Without one (input or output a pipe or a file), raw mode does nothing, lines are read plainly, and colors_enabled() is false.

  • RawMode, restore: raw mode on and off; the terminal is restored at exit and on a panic too
  • KeyReader, KeyDecoder, KeyEvent, Key: key presses
  • MouseMode, MouseTracking, PasteMode: mouse reporting and bracketed paste on and off (both are off unless a program turns them on)
  • InputReader, InputDecoder, Event, MouseEvent, MouseKind, MouseButton: key presses, mouse reports and pastes together
  • LineReader, LineInput, LineEditor, EditStatus, History: readline-style line editing
  • Style, Color, BasicColor, RESET, colors_enabled: colors and text styles
  • move_to, move_up and the other moves, CLEAR_SCREEN and the other sequences: the cursor and the screen
  • input_is_terminal, output_is_terminal, size, Size: the terminal itself

Example

import term;
import [BasicColor, Color, LineInput, Style] from term;

main(): int {
    var prompt = Style(foreground = Color.Basic(BasicColor.Green), bold = true);
    var reader = term.LineReader();
    while (true) {
        match (reader.read_line(prompt.paint("> ", term.colors_enabled()))) {
            Line(text) => {
                print($"you typed {text}");
            }
            Interrupted => {}
            EndOfInput => {
                return 0;
            }
        }
    }
}
