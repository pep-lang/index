term

terminal.pep

The terminal itself: whether the standard streams are one, its size, raw mode, mouse reporting, bracketed paste, and reading keys, mouse reports, pastes and edited lines from it. Each part degrades when there is no terminal (input from a pipe or a file, output to one): raw mode, mouse reporting and bracketed paste do nothing, keys are decoded from the bytes as they come, lines are read plainly, and colors_enabled is false.

Source: terminal.pep

colors_enabled

colors_enabled(): bool

Returns whether to write colors and styles to standard output: it is a terminal, the NO_COLOR environment variable is unset or empty (see no-color.org), and TERM is not dumb. On Windows it also turns on the console's reading of escape sequences, and is false when the console cannot.

Returns

  • true when colors will show

Example

import term;
import [BasicColor, Color, Style] from term;

var error = Style(foreground = Color.Basic(BasicColor.Red));
print(error.paint("failed", term.colors_enabled()));

RawMode

struct RawMode

Raw mode: the terminal hands over each key as it is pressed, without echoing it, editing the line, or turning Ctrl+C into a signal, as an editor or a game needs. Making a RawMode turns it on; exit, or the last reference going away, turns it off again.

Use it in a with block, which turns raw mode off however the block ends. The terminal is also restored when the program ends while raw mode is on: at the end of main or process.exit, on a panic, and on SIGTERM, SIGHUP, SIGINT or SIGQUIT (POSIX).

In raw mode on Linux and macOS, output is raw too: "\n" moves down without returning to the first column, so write "\r\n".

Without a terminal on standard input, raw mode does nothing and active is false. Raw mode is one setting of the whole terminal, so while one RawMode has it on, another is not active either.

Example

import term;

main(): int {
    with (var raw = term.RawMode()) {
        var keys = term.KeyReader();
        print(raw.active ? "press a key\r" : "not a terminal");
        var key = keys.read();
        if (!key.is_empty()) {
            print($"you pressed {key.value()}\r");
        }
    }
    return 0;
}

MouseMode

struct MouseMode

Mouse reporting: while it is on, the terminal sends mouse presses, releases, the wheel and, as tracking says, moves, which InputReader reads as Event.Mouse. Making a MouseMode turns it on; exit, or the last reference going away, turns it off again. It is off unless a program asks: without it the terminal keeps the mouse, to select and scroll.

Use it in a with block, inside a RawMode's. Like raw mode it is turned off when the program ends while it is on: at the end of main or process.exit, on a panic, and on SIGTERM, SIGHUP, SIGINT or SIGQUIT (POSIX).

On Linux and macOS it asks the terminal for xterm's reports in SGR encoding (mode 1006), which every current terminal speaks. On Windows it turns on the console's mouse input, and turns Quick Edit (selecting with the mouse) off while it is on.

Without a terminal on standard input and output it does nothing, and active is false. Mouse reporting is one setting of the whole terminal, so while one MouseMode has it on, another is not active.

Example

import term;
import [Event] from term;

main(): int {
    with (var raw = term.RawMode()) {
        with (var mouse = term.MouseMode()) {
            var input = term.InputReader();
            var event = input.read();
            if (!event.is_empty()) {
                match (event.value()) {
                    Key(key) => print($"key {key}\r"),
                    Mouse(click) => print($"mouse {click}\r"),
                    Paste(text, truncated) => print($"paste {text}\r"),
                    else => {}
                }
            }
        }
    }
    return 0;
}

PasteMode

struct PasteMode

Bracketed paste: while it is on, the terminal marks the start and end of text pasted into it, so InputReader reads each paste whole, as one Event.Paste, rather than as typed keys, and a paste with line ends does not run as one command per line. Making a PasteMode turns it on; exit, or the last reference going away, turns it off again. It is off unless a program asks.

Use it in a with block. Like raw mode it is turned off when the program ends while it is on: at the end of main or process.exit, on a panic, and on SIGTERM, SIGHUP, SIGINT or SIGQUIT (POSIX).

It asks for xterm's bracketed paste (mode 2004), which current terminals on Linux and macOS, and Windows Terminal, have. A terminal without it ignores the request, and its pastes arrive as typed keys, as they do in the older Windows console. On Windows it turns on the console's reading of escape sequences, which the request needs.

Without a terminal on standard input and output it does nothing, and active is false. Bracketed paste is one setting of the whole terminal, so while one PasteMode has it on, another is not active.

Example

import term;
import [LineInput] from term;

main(): int {
    with (var paste = term.PasteMode()) {
        var reader = term.LineReader();
        match (reader.read_line("> ")) {
            Line(text) => print($"read {text}"),
            Interrupted => {}
            EndOfInput => {}
        }
    }
    return 0;
}

InputReader

struct InputReader

Reads what the user does from standard input, decoding it with an InputDecoder: key presses and, while a MouseMode or PasteMode is on, mouse reports and pastes. A paste whose end does not come within a second is given back as typed keys.

On a terminal in raw mode, each key arrives as it is pressed. Outside raw mode the terminal sends nothing until Enter. Without a terminal, the input's bytes are decoded as they come: text gives Key.Char events, and line ends give Key.Enter.

LineReader

struct LineReader

Reads lines from standard input for a REPL or a prompt, with editing and history (see LineEditor for the keys) when standard input and output are a terminal, and plainly otherwise. While a PasteMode is on, a paste goes into the line whole, line ends and all, without submitting it.

Example

import term;
import [LineInput] from term;

main(): int {
    var reader = term.LineReader();
    while (true) {
        match (reader.read_line("> ")) {
            Line(text) => {
                print($"you typed {text}");
            }
            Interrupted => {}
            EndOfInput => {
                return 0;
            }
        }
    }
}
