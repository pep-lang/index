sqlite

SQLite bindings: open a database, run SQL, prepare statements with bound parameters, read typed rows or decode them into structs, and run transactions.

Bring it in with import sqlite. It links the system's SQLite: libsqlite3 on Linux (apt install libsqlite3-dev) and macOS, and winsqlite3, part of Windows 10 and later, on Windows. Every call that can fail returns a SqliteResult<T>, whose error holds SQLite's result code and message.

  • Database: a connection: open, execute, prepare, query<T>, begin/commit/rollback and transaction
  • Statement: a prepared statement: bind, step, the column_ readers, read<T>, reset, finalize
  • Value: one value of any of SQLite's storage classes
  • SqliteError, SqliteResult<T>: errors
  • OPEN_READ_ONLY and the other OPEN_ flags, version

Example

import sqlite;

struct Book {
    var title: String;
    var year: int;
}

main(): int {
    var db = sqlite.Database.open_in_memory().value();
    db.execute("CREATE TABLE books (title TEXT NOT NULL, year INTEGER)").value();
    var insert = db.prepare("INSERT INTO books VALUES (:title, :year)").value();
    insert.bind(":title", "Dune").value();
    insert.bind(":year", 1965).value();
    insert.step().value();
    for (var book in db.query<Book>("SELECT title, year FROM books").value()) {
        print($"{book.title} ({book.year})");   # Dune (1965)
    }
    return 0;
}

OPEN_READ_ONLY

const OPEN_READ_ONLY = 0x1

Opens the database for reading only; it must exist.

OPEN_READ_WRITE

const OPEN_READ_WRITE = 0x2

Opens the database for reading and writing.

OPEN_CREATE

const OPEN_CREATE = 0x4

With OPEN_READ_WRITE, creates the database when it does not exist.

OPEN_URI

const OPEN_URI = 0x40

Reads the path as a URI (file:data.db?mode=ro).

OPEN_MEMORY

const OPEN_MEMORY = 0x80

Opens an in-memory database, whatever the path says.

Database

struct Database

A connection to an SQLite database.

Open one with open (a file) or open_in_memory. execute runs SQL that returns no rows; prepare makes a Statement for SQL with parameters or rows; query<T> runs a query and decodes every row into a struct. transaction runs a function inside a transaction that it commits, or rolls back when the function fails.

The connection is closed when the last reference to it, and to every statement prepared on it, goes away, or earlier with close(). It belongs to one thread at a time.

Example

import sqlite;

struct User {
    var id: long;
    var name: String;
}

main(): int {
    var db = sqlite.Database.open("app.db").value();
    db.execute("CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY, name TEXT)").value();
    db.execute("INSERT INTO users (name) VALUES (?)", [sqlite.Value.Text("Ada")]).value();
    for (var user in db.query<User>("SELECT id, name FROM users").value()) {
        print($"{user.id}: {user.name}");
    }
    return 0;
}

Example

import sqlite;

var db = sqlite.Database.open_in_memory().value();
db.execute("CREATE TABLE accounts (id INTEGER, balance INTEGER)").value();
var moved = db.transaction<void>((): sqlite.SqliteResult<void> => {
    db.execute("UPDATE accounts SET balance = balance - 10 WHERE id = 1")?;
    db.execute("UPDATE accounts SET balance = balance + 10 WHERE id = 2")?;
    return sqlite.SqliteResult<void>.ok();
});

SqliteError

struct SqliteError

An error SQLite reported: its result code and its message.

code is SQLite's extended result code, such as 2067 (SQLITE_CONSTRAINT_UNIQUE); primary_code() is its low byte, the primary code, such as 19 (SQLITE_CONSTRAINT). See <https://sqlite.org/rescode.html> for the codes.

sqlite3.pep

The parts of SQLite's C API (sqlite3.h) the module calls, private to the module. Each declaration is the C function of the same name, with C's types: sqlite3* and sqlite3_stmt* are void*, sqlite3_int64 is long.

Which library is linked, per platform:

  • Linux: libsqlite3.so (apt install libsqlite3-dev).
  • macOS: libsqlite3.dylib, which the SDK provides.
  • Windows: winsqlite3.dll, which Windows 10 and later ship in System32, through winsqlite3.lib from the Windows SDK.

Statement

struct Statement

A prepared SQL statement, made by Database.prepare.

Bind its parameters with bind, then call step until it returns false: each true is a row, read with the column_ methods or decoded into a struct with read<T>(). reset runs it again, keeping the bindings; clear_bindings sets every parameter back to NULL.

Parameters are numbered from 1, as SQLite numbers them (?, ?1), or named (:name, @name, $name, with the prefix in the name you bind). Columns are numbered from 0.

The statement keeps its database open. It is finalized when the last reference to it goes away, or earlier with finalize().

Example

import sqlite;

var db = sqlite.Database.open_in_memory().value();
db.execute("CREATE TABLE t (n INTEGER, name TEXT)").value();
var insert = db.prepare("INSERT INTO t VALUES (?, :name)").value();
insert.bind(1, 7).value();
insert.bind(":name", "seven").value();
insert.step().value();
var query = db.prepare("SELECT n, name FROM t").value();
while (query.step().value()) {
    print($"{query.column_long(0).value()} {query.column_text(1).value()}");
}

read

read<T>(): SqliteResult<T>

Decodes the current row into a T, as json.from_json decodes an object whose keys are the column names.

A column fills the property of its name (or of its [Name("...")]); a NULL column is null, so it fills an Optional property as none. Integers fill number properties, text Strings and blobs u8[] properties. A column no property names is ignored, and a property no column names keeps its default, unless it is [Required].

Type parameters

  • T — the struct to decode into

Returns

  • the decoded row, or an error with code SQLITE_MISMATCH (20) whose message is the conversion's ($.age: expected a number, found a string)

Panics

  • if there is no current row
