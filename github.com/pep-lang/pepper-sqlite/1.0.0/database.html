sqlite

database.pep

Database: a connection to an SQLite database, and its transactions.

Source: database.pep

OPEN_READ_ONLY

const OPEN_READ_ONLY = 0x1

Opens the database for reading only; it must exist.

OPEN_READ_WRITE

const OPEN_READ_WRITE = 0x2

Opens the database for reading and writing.

OPEN_CREATE

const OPEN_CREATE = 0x4

With OPEN_READ_WRITE, creates the database when it does not exist.

OPEN_URI

const OPEN_URI = 0x40

Reads the path as a URI (file:data.db?mode=ro).

OPEN_MEMORY

const OPEN_MEMORY = 0x80

Opens an in-memory database, whatever the path says.

Database

struct Database

A connection to an SQLite database.

Open one with open (a file) or open_in_memory. execute runs SQL that returns no rows; prepare makes a Statement for SQL with parameters or rows; query<T> runs a query and decodes every row into a struct. transaction runs a function inside a transaction that it commits, or rolls back when the function fails.

The connection is closed when the last reference to it, and to every statement prepared on it, goes away, or earlier with close(). It belongs to one thread at a time.

Example

import sqlite;

struct User {
    var id: long;
    var name: String;
}

main(): int {
    var db = sqlite.Database.open("app.db").value();
    db.execute("CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY, name TEXT)").value();
    db.execute("INSERT INTO users (name) VALUES (?)", [sqlite.Value.Text("Ada")]).value();
    for (var user in db.query<User>("SELECT id, name FROM users").value()) {
        print($"{user.id}: {user.name}");
    }
    return 0;
}

Static methods

open

static open(path: String, flags: int = OPEN_READ_WRITE | OPEN_CREATE): SqliteResult<Database>

Opens (by default, creating) the database file at path.

":memory:" and an empty path open a private in-memory database, and a temporary on-disk one, as SQLite documents.

Parameters

  • path — the database file
  • flags — OPEN_READ_ONLY, or OPEN_READ_WRITE with or without OPEN_CREATE, plus OPEN_URI or OPEN_MEMORY

Returns

  • the connection, or the error (SQLITE_CANTOPEN, 14, when the file cannot be opened)

open_in_memory

static open_in_memory(): SqliteResult<Database>

Opens a new, private in-memory database, gone when it is closed.

Returns

  • the connection, or the error

Methods

is_open

is_open(): bool

Reports whether the connection is open: false after close().

Returns

  • true until the connection is closed

close

close()

Closes the connection now rather than when the last reference to it goes away. Statements prepared on it keep it open until they are finalized, but no longer through this Database. Calling it again does nothing.

execute

execute(sql: String): SqliteResult<void>

Runs sql, which may hold several statements separated by ;, and discards any rows.

Parameters

  • sql — the SQL

Returns

  • nothing, or the error of the first statement that fails; the statements before it have run

Panics

  • if the database is closed

execute

execute(sql: String, parameters: Value[]): SqliteResult<long>

Runs one statement with parameters bound to it in order, and discards any rows.

Parameters

  • sql — one SQL statement
  • parameters — one value per parameter

Returns

  • the number of rows it inserted, changed or deleted, or the error; for any other statement, the count of the last write before it, as SQLite's changes() reports

Panics

  • if the database is closed

prepare

prepare(sql: String): SqliteResult<Statement>

Compiles the first statement in sql.

Parameters

Returns

Panics

Returns

set_busy_timeout

set_busy_timeout(milliseconds: int)

Sets how long a statement waits for a lock another connection holds before it fails with SQLITE_BUSY (5). The default is not to wait.

Parameters

Commits the open transaction (COMMIT).

transaction

transaction<T>(body: () => SqliteResult<T>): SqliteResult<T>

Runs body inside a transaction: commits when it returns Ok, and rolls back when it returns an error or the commit fails.

Type parameters

  • T — what body returns on success

Parameters

  • body — the work to do; return its errors (with ?) to roll back

Returns

  • body's result, or the error of begin or commit

Panics

  • if the database is closed

Example

import sqlite;

var db = sqlite.Database.open_in_memory().value();
db.execute("CREATE TABLE accounts (id INTEGER, balance INTEGER)").value();
var moved = db.transaction<void>((): sqlite.SqliteResult<void> => {
    db.execute("UPDATE accounts SET balance = balance - 10 WHERE id = 1")?;
    db.execute("UPDATE accounts SET balance = balance + 10 WHERE id = 2")?;
    return sqlite.SqliteResult<void>.ok();
});
