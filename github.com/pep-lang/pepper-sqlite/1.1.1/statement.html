Statement

struct Statement

A prepared SQL statement, made by Database.prepare.

Bind its parameters with bind, then call step until it returns false: each true is a row, read with the column_ methods or decoded into a struct with read<T>(). reset runs it again, keeping the bindings; clear_bindings sets every parameter back to NULL.

Parameters are numbered from 1, as SQLite numbers them (?, ?1), or named (:name, @name, $name, with the prefix in the name you bind). Columns are numbered from 0.

The statement keeps its database open. It is finalized when the last reference to it goes away, or earlier with finalize().

Example

import sqlite;

var db = sqlite.Database.open_in_memory().value();
db.execute("CREATE TABLE t (n INTEGER, name TEXT)").value();
var insert = db.prepare("INSERT INTO t VALUES (?, :name)").value();
insert.bind(1, 7).value();
insert.bind(":name", "seven").value();
insert.step().value();
var query = db.prepare("SELECT n, name FROM t").value();
while (query.step().value()) {
    print($"{query.column_long(0).value()} {query.column_text(1).value()}");
}

read

read<T>(): SqliteResult<T>

Decodes the current row into a T, as json.from_json decodes an object whose keys are the column names.

A column fills the property of its name (or of its [Name("...")]); a NULL column is null, so it fills an Optional property as none. Integers fill number properties, text Strings and blobs u8[] properties. A column no property names is ignored, and a property no column names keeps its default, unless it is [Required].

Type parameters

  • T — the struct to decode into

Returns

  • the decoded row, or an error with code SQLITE_MISMATCH (20) whose message is the conversion's ($.age: expected a number, found a string)

Panics

  • if there is no current row
