Value: one SQLite value of any storage class.

Source: value.pep

Value

enum Value

A value as SQLite stores it: NULL, an integer, a floating-point number, text or a blob. Statement.column reads one, Statement.bind binds one, and Database.execute takes them as parameters.

Example

import sqlite;

var parameters = [sqlite.Value.Integer(1), sqlite.Value.Text("Ada"), sqlite.Value.Null];
