msgpack

value.pep

The dynamic value: Value, one item of MessagePack or CBOR whose shape is not known ahead, and DecodeError, what decoding reports.

Source: value.pep

Value

enum Value

One MessagePack or CBOR item, decoded without a type to read it into, or built to be encoded.

One type serves both formats. A case only one of them has is written by the other as its nearest form (see msgpack.encode and cbor.encode). to_string() writes it in CBOR's diagnostic notation.

Example

import msgpack;

main(): int {
    var value = msgpack.decode<msgpack.Value>([0x82 as u8, 0xa1, 0x61, 0x01, 0xa1, 0x62, 0x02]).value();
    assert(value.to_string() == "{\"a\": 1, \"b\": 2}", "a map");
    assert(value.get("b").value().to_string() == "2", "a member");
    return 0;
}

Map

Map(entries: Array<(Value, Value)>)

A map: its keys and values in order. Keys may be any value, and the decoders keep duplicates as they come.

Simple

A CBOR simple value other than false, true, null and undefined: 0 to 19 or 32 to 255 (cbor.encode writes the others as undefined).

Methods

get

get(key: String): Value?

Returns the value of the first entry whose key is the string key, when this is a Map.

Parameters

  • key — the key to look for

Returns

  • the entry's value, or empty when this is not a map or has no such key

to_string

to_string(): String

Returns the value in CBOR's diagnostic notation (RFC 8949, section 8): {"a": [1, h'ff', 2(h'01')], "b": -1.5}.

Strings are quoted as JSON quotes them, a float is written as Pepper writes a double (1.5, 1e+300, Infinity, NaN), and an extension, which the notation has no form for, as ext(kind, h'data').

Returns

  • the text

DecodeError

struct DecodeError

Why decoding failed: input that is not well formed, or a well-formed value that does not convert to the type asked for.

Fields

message

var message: String

What is wrong, worded like a compiler error (unexpected end of input), without the place.

offset

var offset: ulong

The byte offset, from 0, of the item the error is about; 0 for a conversion error.

value_path

var value_path: String

Where in the value a conversion error is, as a path from the root $ ($.server.port, $.tags[2]); empty for an error in the input's form.

Constructor

DecodeError()

construct(message: String = "", offset: ulong = 0, value_path: String = "")

Creates an error.

Parameters

  • message — what is wrong
  • offset — the byte offset of the item it is about
  • value_path — the path of a conversion error, or empty

Methods

to_string

to_string(): String

Returns the error with its place: byte 12: unexpected end of input, or $.port: expected an integer, found a string.

Returns

  • the text
