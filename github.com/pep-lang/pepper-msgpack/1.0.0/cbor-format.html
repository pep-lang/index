msgpack

cbor/format.pep

CBOR itself (RFC 8949): encode writes a value in the format and decode reads one back.

Source: cbor/format.pep

encode

encode<T>(value: T): u8[]

Writes value as CBOR, converting it as msgpack.to_value does.

The output is in the RFC's preferred serialization: each integer and length in its shortest form, and each float as the narrowest of half, single and double precision that keeps its value exactly (NaN as the half 0xf97e00). Lengths are always definite, and map entries keep their order. A Tag is written as a tag, and a MessagePack Extension, which CBOR has no form for, as a byte string of its data. A Simple value from 20 to 31, which is not a simple value of its own, is written as undefined.

Type parameters

  • T — the type of the value

Parameters

  • value — the value to write

Returns

  • the encoded bytes

Example

import digest;
import msgpack.cbor;

struct Point {
    var x: int;
    var y: int;
}

main(): int {
    var p = Point();
    p.x = 1;
    p.y = -1;
    assert(digest.to_hex(cbor.encode(p)) == "a2617801617920", "a map");
    return 0;
}

decode

decode<T>( bytes: u8[], unknown_keys: json.UnknownKeys = json.UnknownKeys.Ignore, max_depth: ulong = 256 ): Result<T, msgpack.DecodeError>

Reads a CBOR value from bytes and converts it to a T, as msgpack.from_value does; decode<msgpack.Value> gives the value itself.

Every well-formed item reads: tags (as Tag, which converts as the item it tags), simple values, half-precision floats, and indefinite-length strings, arrays and maps, whose chunks a string joins into one.

Decoding is safe for untrusted input: every failure is an error, never a panic. A declared length longer than the bytes that remain fails before anything is allocated, so a 4 GB length prefix in a short input costs nothing, and arrays, maps and tags may nest only max_depth deep. bytes must hold exactly one item; a text string must be UTF-8, and a reserved additional-information value, a break outside an indefinite-length item, or a chunk of the wrong type is an error.

Type parameters

  • T — the type to convert to

Parameters

  • bytes — the encoded value
  • unknown_keys — what to do with a map key that names no property
  • max_depth — how deep arrays, maps and tags may nest

Returns

  • the value, or the first error: one in the input's form, at its byte offset, or a conversion error, at its path in the value

Example

import msgpack;
import msgpack.cbor;

main(): int {
    var value = cbor.decode<msgpack.Value>([0xc1 as u8, 0x1a, 0x51, 0x4b, 0x67, 0xb0]).value();
    assert(value.to_string() == "1(1363896240)", "a tag");

    var huge = cbor.decode<msgpack.Value>([0x5a as u8, 0xff, 0xff, 0xff, 0xff]);
    assert(huge.is_err(), "a 4 GB byte string in 5 bytes");
    return 0;
}
