msgpack

convert.pep

Struct conversion: to_value turns Pepper values into a Value and from_value turns one back, through reflection, with the attributes of the serialize module, as json.to_json and json.from_json do. Both formats encode and decode through these.

Source: convert.pep

to_value

to_value<T>(value: T): Value

Converts value to a Value.

T may be a number type (an Integer, Unsigned or Float), bool, String, u8[] (a Binary), Optional<U> (the value, or Null), Array<U>, a map with String keys (HashMap, OrderedMap or Map), Value itself, an enum, or a struct, whose public properties become a map's entries in declaration order, keyed by name. A property takes its key from [Name("key")] when it has one, and is left out when marked [Ignore]. A struct reference that holds no object is Null.

An enum takes the form json.to_json gives it (a case that carries nothing as its name, one that carries values as a map, and [Tag] and [Untagged] as for JSON), converted from JSON, so a u8[] inside a case is an array of integers there.

A type it cannot convert is a compile error.

Type parameters

  • T — the type of the value

Parameters

  • value — the value to convert

Returns

  • the value as a Value

Example

import msgpack;

struct Point {
    var x: int;
    var y: int;
}

main(): int {
    var p = Point();
    p.x = 1;
    p.y = 2;
    assert(msgpack.to_value(p).to_string() == "{\"x\": 1, \"y\": 2}", "a map");
    return 0;
}

from_value

from_value<T>(value: Value, unknown_keys: json.UnknownKeys = json.UnknownKeys.Ignore): Result<T, DecodeError>

Converts a Value to a T, the reverse of to_value.

A struct is made with its constructor that takes no arguments, then each entry of the map whose key names a property is read in. A missing key leaves its property at its default, unless the property is marked [Required], which makes it an error; a property marked [Ignore] is never read. A key that names no property is skipped, or with unknown_keys = msgpack.UnknownKeys.Reject is an error.

An integer converts to an integer type it fits, and to float or double; a u8[] reads a Binary or an array of integers; Null converts only to an Optional (as none), a struct reference, and Value. A Tag converts as the item it tags, so a tagged value reads into the type of its content.

Type parameters

  • T — the type to convert to

Parameters

  • value — the value
  • unknown_keys — what to do with a map key that names no property

Returns

  • the converted value, or the first error, whose value_path says where in the value it is

Example

import msgpack;

struct Point {
    var x: int;
    var y: int;
}

main(): int {
    var entries = Array<(msgpack.Value, msgpack.Value)>();
    entries.append((msgpack.Value.String("y"), msgpack.Value.Integer(2)));
    var p = msgpack.from_value<Point>(msgpack.Value.Map(entries));
    assert(p.value().y == 2, "a property");
    return 0;
}
