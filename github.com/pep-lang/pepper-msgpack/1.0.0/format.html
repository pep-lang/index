msgpack

format.pep

MessagePack itself: encode writes a value in the format and decode reads one back.

Source: format.pep

encode

encode<T>(value: T): u8[]

Writes value as MessagePack, converting it as to_value does.

Each item takes the shortest form that holds it: a small integer is one byte, a string under 32 bytes a fixstr, and so on. A float is written as float 32 when that keeps its value exactly, else as float 64. The cases MessagePack has no form for are written as their nearest: Undefined and Simple as nil, a Tag as the item it tags, and a Negative as a float 64.

Type parameters

  • T — the type of the value

Parameters

  • value — the value to write

Returns

  • the encoded bytes

Panics

  • if a string, byte string, extension, array or map holds 2^32 items or more, which MessagePack cannot write

Example

import digest;
import msgpack;

struct Point {
    var x: int;
    var y: int;
}

main(): int {
    var p = Point();
    p.x = 1;
    p.y = -1;
    assert(digest.to_hex(msgpack.encode(p)) == "82a17801a179ff", "a fixmap");
    return 0;
}

decode

decode<T>( bytes: u8[], unknown_keys: json.UnknownKeys = json.UnknownKeys.Ignore, max_depth: ulong = 256 ): Result<T, DecodeError>

Reads a MessagePack value from bytes and converts it to a T, as from_value does; decode<Value> gives the value itself.

Decoding is safe for untrusted input: every failure is an error, never a panic. A declared length longer than the bytes that remain fails before anything is allocated, so a 4 GB length prefix in a short input costs nothing, and items may nest only max_depth deep. bytes must hold exactly one value; a string must be UTF-8, and the never-used byte 0xc1 is an error.

Type parameters

  • T — the type to convert to

Parameters

  • bytes — the encoded value
  • unknown_keys — what to do with a map key that names no property
  • max_depth — how deep arrays and maps may nest

Returns

  • the value, or the first error: one in the input's form, at its byte offset, or a conversion error, at its path in the value

Example

import msgpack;

struct Point {
    var x: int;
    var y: int;
}

main(): int {
    var p = msgpack.decode<Point>([0x82 as u8, 0xa1, 0x78, 0x01, 0xa1, 0x79, 0xff]);
    assert(p.value().y == -1, "a property");

    var cut = msgpack.decode<Point>([0x81 as u8, 0xa1, 0x78]);
    assert(cut.error().to_string() == "byte 3: unexpected end of input", "where");
    return 0;
}
