msgpack

MessagePack: encode Pepper values as compact binary and decode them back, with structs driven by the attributes of the serialize module, as json converts them. The msgpack.cbor module does the same for CBOR (RFC 8949), with the same Value and DecodeError.

Bring it in with import msgpack. Decoding is safe for untrusted input: a malformed value is a DecodeError with its byte offset, never a panic; a declared length is checked against the bytes that remain before anything is allocated; and nesting is capped.

  • encode, decode: MessagePack bytes to and from any convertible type
  • Value: a decoded value of no fixed type, or one built to encode
  • to_value, from_value: struct conversion to and from a Value
  • DecodeError: why decoding failed
  • UnknownKeys: json's choice of what decoding does with a map key that names no property

Example

import msgpack;
import serialize;

struct Reading {
    [Required]
    var sensor: String;
    var celsius: double;
    [Name("raw")]
    var samples: u8[];
}

main(): int {
    var reading = Reading();
    reading.sensor = "porch";
    reading.celsius = 21.5;
    reading.samples = [1 as u8, 2, 3];
    var bytes = msgpack.encode(reading);
    var back = msgpack.decode<Reading>(bytes).value();
    assert(back.sensor == "porch" && back.samples.count == 3, "a round trip");

    var any = msgpack.decode<msgpack.Value>(bytes).value();
    assert(any.get("raw").value().to_string() == "h'010203'", "a byte string");
    return 0;
}

msgpack.cbor

CBOR (RFC 8949): encode Pepper values as Concise Binary Object Representation and decode them back, with structs driven by the attributes of the serialize module, as json converts them.

Bring it in with import msgpack.cbor. It shares msgpack's Value (with CBOR's tags, simple values and undefined) and DecodeError, which it exports too, and converts structs as msgpack.to_value and msgpack.from_value do. Decoding is as safe for untrusted input as msgpack.decode: errors, never panics, lengths checked against the input, and nesting capped.

  • encode, decode: CBOR bytes to and from any convertible type
  • Value, DecodeError, UnknownKeys: msgpack's, under this module's name

Example

import msgpack.cbor;

struct Credential {
    var id: u8[];
    var counter: int;
}

main(): int {
    var credential = Credential();
    credential.id = [0xca as u8, 0xfe];
    credential.counter = 7;
    var bytes = cbor.encode(credential);
    var back = cbor.decode<Credential>(bytes).value();
    assert(back.counter == 7 && back.id[1] == 0xfe, "a round trip");

    var any = cbor.decode<cbor.Value>(bytes).value();
    assert(any.to_string() == "{\"id\": h'cafe', \"counter\": 7}", "diagnostic notation");
    return 0;
}

Source: cbor/module.pep

cbor/format.pep

CBOR itself (RFC 8949): encode writes a value in the format and decode reads one back.

Source: cbor/format.pep

encode

encode<T>(value: T): u8[]

Writes value as CBOR, converting it as msgpack.to_value does.

The output is in the RFC's preferred serialization: each integer and length in its shortest form, and each float as the narrowest of half, single and double precision that keeps its value exactly (NaN as the half 0xf97e00). Lengths are always definite, and map entries keep their order. A Tag is written as a tag, and a MessagePack Extension, which CBOR has no form for, as a byte string of its data. A Simple value from 20 to 31, which is not a simple value of its own, is written as undefined.

Type parameters

  • T — the type of the value

Parameters

  • value — the value to write

Returns

  • the encoded bytes

Example

import digest;
import msgpack.cbor;

struct Point {
    var x: int;
    var y: int;
}

main(): int {
    var p = Point();
    p.x = 1;
    p.y = -1;
    assert(digest.to_hex(cbor.encode(p)) == "a2617801617920", "a map");
    return 0;
}

decode

decode<T>( bytes: u8[], unknown_keys: json.UnknownKeys = json.UnknownKeys.Ignore, max_depth: ulong = 256 ): Result<T, msgpack.DecodeError>

Reads a CBOR value from bytes and converts it to a T, as msgpack.from_value does; decode<msgpack.Value> gives the value itself.

Every well-formed item reads: tags (as Tag, which converts as the item it tags), simple values, half-precision floats, and indefinite-length strings, arrays and maps, whose chunks a string joins into one.

Decoding is safe for untrusted input: every failure is an error, never a panic. A declared length longer than the bytes that remain fails before anything is allocated, so a 4 GB length prefix in a short input costs nothing, and arrays, maps and tags may nest only max_depth deep. bytes must hold exactly one item; a text string must be UTF-8, and a reserved additional-information value, a break outside an indefinite-length item, or a chunk of the wrong type is an error.

Type parameters

  • T — the type to convert to

Parameters

  • bytes — the encoded value
  • unknown_keys — what to do with a map key that names no property
  • max_depth — how deep arrays, maps and tags may nest

Returns

  • the value, or the first error: one in the input's form, at its byte offset, or a conversion error, at its path in the value

Example

import msgpack;
import msgpack.cbor;

main(): int {
    var value = cbor.decode<msgpack.Value>([0xc1 as u8, 0x1a, 0x51, 0x4b, 0x67, 0xb0]).value();
    assert(value.to_string() == "1(1363896240)", "a tag");

    var huge = cbor.decode<msgpack.Value>([0x5a as u8, 0xff, 0xff, 0xff, 0xff]);
    assert(huge.is_err(), "a 4 GB byte string in 5 bytes");
    return 0;
}

convert.pep

Struct conversion: to_value turns Pepper values into a Value and from_value turns one back, through reflection, with the attributes of the serialize module, as json.to_json and json.from_json do. Both formats encode and decode through these.

Source: convert.pep

to_value

to_value<T>(value: T): Value

Converts value to a Value.

T may be a number type (an Integer, Unsigned or Float), bool, String, u8[] (a Binary), Optional<U> (the value, or Null), Array<U>, a map with String keys (HashMap, OrderedMap or Map), Value itself, an enum, or a struct, whose public properties become a map's entries in declaration order, keyed by name. A property takes its key from [Name("key")] when it has one, and is left out when marked [Ignore]. A struct reference that holds no object is Null.

An enum takes the form json.to_json gives it (a case that carries nothing as its name, one that carries values as a map, and [Tag] and [Untagged] as for JSON), converted from JSON, so a u8[] inside a case is an array of integers there.

A type it cannot convert is a compile error.

Type parameters

  • T — the type of the value

Parameters

  • value — the value to convert

Returns

  • the value as a Value

Example

import msgpack;

struct Point {
    var x: int;
    var y: int;
}

main(): int {
    var p = Point();
    p.x = 1;
    p.y = 2;
    assert(msgpack.to_value(p).to_string() == "{\"x\": 1, \"y\": 2}", "a map");
    return 0;
}

from_value

from_value<T>(value: Value, unknown_keys: json.UnknownKeys = json.UnknownKeys.Ignore): Result<T, DecodeError>

Converts a Value to a T, the reverse of to_value.

A struct is made with its constructor that takes no arguments, then each entry of the map whose key names a property is read in. A missing key leaves its property at its default, unless the property is marked [Required], which makes it an error; a property marked [Ignore] is never read. A key that names no property is skipped, or with unknown_keys = msgpack.UnknownKeys.Reject is an error.

An integer converts to an integer type it fits, and to float or double; a u8[] reads a Binary or an array of integers; Null converts only to an Optional (as none), a struct reference, and Value. A Tag converts as the item it tags, so a tagged value reads into the type of its content.

Type parameters

  • T — the type to convert to

Parameters

  • value — the value
  • unknown_keys — what to do with a map key that names no property

Returns

  • the converted value, or the first error, whose value_path says where in the value it is

Example

import msgpack;

struct Point {
    var x: int;
    var y: int;
}

main(): int {
    var entries = Array<(msgpack.Value, msgpack.Value)>();
    entries.append((msgpack.Value.String("y"), msgpack.Value.Integer(2)));
    var p = msgpack.from_value<Point>(msgpack.Value.Map(entries));
    assert(p.value().y == 2, "a property");
    return 0;
}

format.pep

Source: format.pep

encode

encode<T>(value: T): u8[]

Writes value as MessagePack, converting it as to_value does.

Each item takes the shortest form that holds it: a small integer is one byte, a string under 32 bytes a fixstr, and so on. A float is written as float 32 when that keeps its value exactly, else as float 64. The cases MessagePack has no form for are written as their nearest: Undefined and Simple as nil, a Tag as the item it tags, and a Negative as a float 64.

Type parameters

  • T — the type of the value

Parameters

  • value — the value to write

Returns

  • the encoded bytes

Panics

  • if a string, byte string, extension, array or map holds 2^32 items or more, which MessagePack cannot write

Example

import digest;
import msgpack;

struct Point {
    var x: int;
    var y: int;
}

main(): int {
    var p = Point();
    p.x = 1;
    p.y = -1;
    assert(digest.to_hex(msgpack.encode(p)) == "82a17801a179ff", "a fixmap");
    return 0;
}

decode

decode<T>( bytes: u8[], unknown_keys: json.UnknownKeys = json.UnknownKeys.Ignore, max_depth: ulong = 256 ): Result<T, DecodeError>

Reads a MessagePack value from bytes and converts it to a T, as from_value does; decode<Value> gives the value itself.

Decoding is safe for untrusted input: every failure is an error, never a panic. A declared length longer than the bytes that remain fails before anything is allocated, so a 4 GB length prefix in a short input costs nothing, and items may nest only max_depth deep. bytes must hold exactly one value; a string must be UTF-8, and the never-used byte 0xc1 is an error.

Type parameters

  • T — the type to convert to

Parameters

  • bytes — the encoded value
  • unknown_keys — what to do with a map key that names no property
  • max_depth — how deep arrays and maps may nest

Returns

  • the value, or the first error: one in the input's form, at its byte offset, or a conversion error, at its path in the value

Example

import msgpack;

struct Point {
    var x: int;
    var y: int;
}

main(): int {
    var p = msgpack.decode<Point>([0x82 as u8, 0xa1, 0x78, 0x01, 0xa1, 0x79, 0xff]);
    assert(p.value().y == -1, "a property");

    var cut = msgpack.decode<Point>([0x81 as u8, 0xa1, 0x78]);
    assert(cut.error().to_string() == "byte 3: unexpected end of input", "where");
    return 0;
}

value.pep

The dynamic value: Value, one item of MessagePack or CBOR whose shape is not known ahead, and DecodeError, what decoding reports.

Source: value.pep

Value

enum Value

One MessagePack or CBOR item, decoded without a type to read it into, or built to be encoded.

One type serves both formats. A case only one of them has is written by the other as its nearest form (see msgpack.encode and cbor.encode). to_string() writes it in CBOR's diagnostic notation.

Example

import msgpack;

main(): int {
    var value = msgpack.decode<msgpack.Value>([0x82 as u8, 0xa1, 0x61, 0x01, 0xa1, 0x62, 0x02]).value();
    assert(value.to_string() == "{\"a\": 1, \"b\": 2}", "a map");
    assert(value.get("b").value().to_string() == "2", "a member");
    return 0;
}

Methods

get

get(key: String): Value?

Returns the value of the first entry whose key is the string key, when this is a Map.

Parameters

  • key — the key to look for

Returns

  • the entry's value, or empty when this is not a map or has no such key

to_string

to_string(): String

Returns the value in CBOR's diagnostic notation (RFC 8949, section 8): {"a": [1, h'ff', 2(h'01')], "b": -1.5}.

Strings are quoted as JSON quotes them, a float is written as Pepper writes a double (1.5, 1e+300, Infinity, NaN), and an extension, which the notation has no form for, as ext(kind, h'data').

Returns

  • the text

DecodeError

struct DecodeError

Why decoding failed: input that is not well formed, or a well-formed value that does not convert to the type asked for.

Fields

What is wrong, worded like a compiler error (unexpected end of input), without the place.

offset

The byte offset, from 0, of the item the error is about; 0 for a conversion error.

Where in the value a conversion error is, as a path from the root $ ($.server.port, $.tags[2]); empty for an error in the input's form.
