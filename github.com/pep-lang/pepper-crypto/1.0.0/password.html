password.pep

Password hashing with Argon2id: hash_password and verify_password.

Source: password.pep

hash_password

hash_password(password: String): Result<String>

Hashes password with Argon2id, under a fresh random salt, for storing.

The result is the standard encoded form ($argon2id$v=19$m=65536,t=2,p=1$<salt>$<hash>), which holds the salt and the cost, so verify_password needs nothing else. The cost is libsodium's interactive level: 64 MiB of memory and 2 passes, about 0.1 s on a desktop CPU, for logins.

Parameters

  • password — the password

Returns

  • the encoded hash, or an error when the memory it needs cannot be allocated

Example

import crypto;

main(): int {
    var stored = crypto.hash_password("correct horse").value();
    print(crypto.verify_password("correct horse", stored));   # true
    print(crypto.verify_password("wrong", stored));           # false
    return 0;
}

verify_password

verify_password(password: String, encoded: String): bool

Checks password against a hash from hash_password, in time that does not depend on where they differ.

Parameters

  • password — the password to check
  • encoded — the stored hash

Returns

  • true when the password matches; false when it does not, or encoded is not an Argon2 hash
