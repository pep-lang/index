crypto

Authenticated encryption, signatures, key exchange, key derivation and password hashing, on libsodium.

Bring it in with import crypto. It links the system's libsodium (1.0.18 or later): apt install libsodium-dev on Linux, brew install libsodium on macOS, and on Windows vcpkg install libsodium:x64-windows-static with that triplet's lib folder on PEPPER_LIBRARY_PATH. Keys, nonces and data are byte arrays (u8[]); a call that can fail returns a Result.

  • ChaCha20Poly1305, Aes256Gcm: AEAD; seal picks a random nonce and open fails on any change
  • SigningKey, VerifyingKey: Ed25519 signatures
  • X25519SecretKey: X25519 key exchange
  • hkdf_sha256: HKDF key derivation
  • hash_password, verify_password: Argon2id password hashing
  • random_bytes: secure random bytes
  • version: the libsodium version

Example

import crypto;

main(): int {
    var cipher = crypto.ChaCha20Poly1305.from_key(crypto.ChaCha20Poly1305.generate_key()).value();
    var sealed = cipher.seal("secret".bytes());
    print(cipher.open(sealed).is_ok());   # true
    return 0;
}

ChaCha20Poly1305

struct ChaCha20Poly1305

ChaCha20-Poly1305 (the IETF variant of RFC 8439): encrypts and authenticates with a 32-byte key.

seal picks a fresh random nonce for each message and puts it in front of the ciphertext, and open reads it back, so the usual calls need no nonce handling. Random 12-byte nonces are safe for about 2^32 messages under one key; use a new key before that. seal_with_nonce and open_with_nonce take the nonce from the caller, for protocols that fix it; never use a nonce twice with one key.

The associated data is authenticated but not encrypted: open fails unless it is given the same bytes seal was.

Example

import crypto;

main(): int {
    var key = crypto.ChaCha20Poly1305.generate_key();
    var cipher = crypto.ChaCha20Poly1305.from_key(key).value();
    var sealed = cipher.seal("attack at dawn".bytes());
    var opened = cipher.open(sealed).value();
    print(opened.count);   # 14
    return 0;
}

Aes256Gcm

struct Aes256Gcm

AES-256-GCM: encrypts and authenticates with a 32-byte key, on the CPU's AES instructions.

It runs only where the CPU has them (x86-64 with AES-NI and PCLMUL, and ARMv8 with its crypto extensions); is_available says whether it can, and from_key fails when it cannot. ChaCha20Poly1305 runs anywhere. Nonces and associated data work as they do for ChaCha20Poly1305.

Example

import crypto;

main(): int {
    if (!crypto.Aes256Gcm.is_available()) {
        return 0;
    }
    var cipher = crypto.Aes256Gcm.from_key(crypto.Aes256Gcm.generate_key()).value();
    var sealed = cipher.seal("attack at dawn".bytes(), "header".bytes());
    print(cipher.open(sealed, "header".bytes()).is_ok());   # true
    return 0;
}

kdf.pep

Key derivation: hkdf_sha256 (RFC 5869).

Source: kdf.pep

hkdf_sha256

hkdf_sha256(input_key: u8[], salt: u8[], info: u8[], size: ulong): Result<u8[]>

Derives size bytes of key material from input_key with HKDF-SHA256 (RFC 5869): extract, then expand.

Use it to turn a shared secret, such as one from X25519SecretKey.shared_secret, into keys. It is not for passwords: those need hash_password, which is slow on purpose.

Parameters

  • input_key — the secret to derive from
  • salt — a non-secret random value, or empty
  • info — what the key is for, such as "app v1 encryption"; keys derived with different info are independent
  • size — how many bytes to derive, at most 8160 (255 * 32)

Returns

  • the derived bytes, or an error when size is over 8160

Example

import crypto;

main(): int {
    var key = crypto.hkdf_sha256(crypto.random_bytes(32), Array<u8>(), "demo".bytes(), 32).value();
    print(key.count);   # 32
    return 0;
}

X25519SecretKey

struct X25519SecretKey

An X25519 secret key, for agreeing on a shared secret with a peer.

Each side makes a key, sends the other its public_key(), and calls shared_secret with the peer's: both get the same 32 bytes. Pass them through hkdf_sha256, with both public keys in info, before using them as a key.

Example

import crypto;

main(): int {
    var alice = crypto.X25519SecretKey.generate();
    var bob = crypto.X25519SecretKey.generate();
    var a = alice.shared_secret(bob.public_key()).value();
    var b = bob.shared_secret(alice.public_key()).value();
    print(a.compare(b) == 0);   # true
    return 0;
}

password.pep

Password hashing with Argon2id: hash_password and verify_password.

Source: password.pep

hash_password

hash_password(password: String): Result<String>

Hashes password with Argon2id, under a fresh random salt, for storing.

The result is the standard encoded form ($argon2id$v=19$m=65536,t=2,p=1$<salt>$<hash>), which holds the salt and the cost, so verify_password needs nothing else. The cost is libsodium's interactive level: 64 MiB of memory and 2 passes, about 0.1 s on a desktop CPU, for logins.

Parameters

  • password — the password

Returns

  • the encoded hash, or an error when the memory it needs cannot be allocated

Example

import crypto;

main(): int {
    var stored = crypto.hash_password("correct horse").value();
    print(crypto.verify_password("correct horse", stored));   # true
    print(crypto.verify_password("wrong", stored));           # false
    return 0;
}

verify_password

SigningKey

struct SigningKey

An Ed25519 secret key, which signs messages.

Make one with generate, or from a stored 32-byte seed with from_seed. Store the seed() secretly; share verifying_key().

Example

import crypto;

main(): int {
    var key = crypto.SigningKey.generate();
    var signature = key.sign("hello".bytes());
    var ok = key.verifying_key().verify("hello".bytes(), signature);
    print(ok);   # true
    return 0;
}

sodium.pep

The parts of libsodium's C API (sodium.h) the module calls, private to the module, and the helpers that move bytes between Pepper arrays and C buffers. Each declaration is the C function of the same name, with C's types: unsigned char* is u8*, unsigned long long and size_t are ulong.

Which library is linked, per platform:

  • Linux: libsodium.so (apt install libsodium-dev).
  • macOS: libsodium.dylib from Homebrew (brew install libsodium), found in /opt/homebrew/lib or /usr/local/lib.
  • Windows: the static libsodium.lib (vcpkg install libsodium:x64-windows-static), whose folder goes on PEPPER_LIBRARY_PATH; it also needs advapi32 for its random numbers.

Source: sodium.pep
