crypto

crypto 1.0.1

Authenticated encryption (ChaCha20-Poly1305, AES-256-GCM), Ed25519 signatures, X25519 key exchange, HKDF and Argon2id password hashing, on libsodium

Pages

  • crypto: Authenticated encryption, signatures, key exchange, key derivation and password hashing, on libsodium.
  • aead.pep: Authenticated encryption with associated data (AEAD): ChaCha20Poly1305 (RFC 8439) and Aes256Gcm.
  • kdf.pep: Key derivation: hkdf_sha256 (RFC 5869).
  • key_exchange.pep: X25519 key exchange (RFC 7748): X25519SecretKey.
  • password.pep: Password hashing with Argon2id: hash_password and verify_password.
  • sign.pep: Ed25519 signatures (RFC 8032): SigningKey and VerifyingKey.
  • sodium.pep: The parts of libsodium's C API (sodium.h) the module calls, private to the module, and the helpers that move bytes between Pepper arrays and C buffers.
