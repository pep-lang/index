Ed25519 signatures (RFC 8032): SigningKey and VerifyingKey.

Source: sign.pep

SEED_SIZE

const SEED_SIZE: ulong = 32

The size in bytes of an Ed25519 seed, the secret a SigningKey is made from.

PUBLIC_KEY_SIZE

const PUBLIC_KEY_SIZE: ulong = 32

The size in bytes of an Ed25519 public key.

SIGNATURE_SIZE

const SIGNATURE_SIZE: ulong = 64

The size in bytes of an Ed25519 signature.

SigningKey

struct SigningKey

An Ed25519 secret key, which signs messages.

Make one with generate, or from a stored 32-byte seed with from_seed. Store the seed() secretly; share verifying_key().

Example

import crypto;

main(): int {
    var key = crypto.SigningKey.generate();
    var signature = key.sign("hello".bytes());
    var ok = key.verifying_key().verify("hello".bytes(), signature);
    print(ok);   # true
    return 0;
}
